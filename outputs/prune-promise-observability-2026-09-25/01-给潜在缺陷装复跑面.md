# 第 57 页 · 给「潜在缺陷」装上复跑面：prune 回取承诺到底有没有受害者

日期 2026-09-25。基线 HEAD `8a2a08a`。这一页不是修缺陷，是给一个**已证到底但没量过影响面**的缺陷
装读数，好让 #33 那条裁决（要不要动热文件 `glm-session` 的组装那一跳）有依据。

## 一、缺陷本身早就证了，缺的是"多大一块"

`src/agent/prune.ts:213` 拼给模型的打桩句：

```ts
PRUNED_PLACEHOLDER + "\n[原文已存附件 " + file + "，需要时 read_file 取回]"
```

`file` 来自 `join(attachmentsDir, …)`，而生产入口 `src/agent/glm-session.ts:620` 把附件目录放在
**事件日志旁边**（`join(dirname(logPath), "prune-attachments")`，即应用数据目录）⇒ 这是绝对路径，
而 `read_file` 走的 `resolveInWorkspace` 第一句就拒绝对路径。
`scripts/probe-prune-recall.ts`（第 51 页入库的那支复现器）真跑 `read_file` 证过：
模型照那句做，拿到的是 `只允许 workspace 相对路径: …/probe-…-c-old.txt`，白跑一轮，
且**被剪掉的原文再没有任何工具够得着**。

修法两族都摆过：① 给 `read_file` 一个窄的第二允许根（要动 `glm-session` 那一跳，而它现在在别人手里）；
② 把这句改成"真做得到的动作"（等于收回 §7.4 的回取能力，属产品裁决）。
**两边都没做**，因为当时没人答得出：这句话发射过几次？模型照做过几次？——
"听起来严重"不是施工依据，本仓的规矩是**先数，再动**。

## 二、新增复跑面 `scripts/replay/prune-promise.ts`（读数，不是门）

跑法：`node --import tsx scripts/replay/prune-promise.ts`（与 `corpus-inventory` / `ask-density` 同一族：
不进 `gate-manifest`，也不占 `package.json`——那两个键名从来只在脚本头的"登记项"注释里）。

它把四种 0 分开，因为这四种 0 的**处置彼此相反**：

| 态 | 判据 | 结论与处置 |
| --- | --- | --- |
| 活缺陷 | `attemptFailed > 0 && attemptOk === 0` | **红（exit 1）**：模型照做过且每一次都收到失败回执 ⇒ 这时才允许去动热文件 |
| 通道可用 | `attemptOk > 0` | 绿，#33 降级为"省一次失败" |
| 无人照做 | `stubs > 0 && attempts === 0` | 绿，但明写「**不能读成没问题**」——走不通的路本来就没人走 |
| 从没发射 | `stubs === 0` | 绿，判"潜在"，别为它动组装那一跳 |
| 没有尺 | 零语料 / 有 `.jsonl` 却零 `tool_call` | 复用 `corpusProblem`，红着退出（与两支同族读数同一把尺） |

两条形状上的坑单独处理：
- **join 键**：`tool_call.id` ↔ `tool_result.callId`（本仓 09-21 就是读错这个键得到一片零假读数）。
  这里配一条"配不上 ⇒ 记 `attemptNoResult`，既不冒充失败也不冒充成功"的用例；
  并且**无回执不算活缺陷**——拿没证据的那一类去要真钱/热文件，正是本仓点名的偏信。
- **读数范围是字段不是感觉**：打印 `missingRoots`（真会话那一支不在时，这个 0 只覆盖合成语料）。

## 四、判卷与牙（`tests/replay-prune-promise.test.ts` 8 条 + 五格突变）

写这批用例的过程本身抓到一支真 bug：
`new RegExp(pattern).u.exec(...)` 被解析成"取 `.u` 属性"⇒ `undefined.exec` ⇒
**第一次跑 7/8 全红**（`TypeError: Cannot read properties of undefined`）。
`u` 是 flag，必须 `new RegExp(pattern, "u")`。已在源码注释里留下这句，避免下一次再踩。

| 突变（一次性、改完逐字复原） | 红几条 | 红的是谁 |
| --- | --- | --- |
| M1 join 键改读 `id`（回执配不上调用） | 3 | 活缺陷格 / 通道可用格 / run_shell 格 |
| M2 「绝对路径」判据放宽成"非空" | 1 | 「数的是绝对路径那一类」格 |
| M3 附件路径只认 `path` 参数位 | 1 | 「任意参数位都算照做」格 |
| M4 承诺根本不数（`if (false)`） | 4 | 四格数 stubs 的全红 |
| M5 把"无回执"也算成活缺陷 | 1 | join 键那格（它断的是 `无从判定`） |

五格全有观测者，探针跑完打印「恢复后逐字一致 ✅」后自删（不留进仓）。
