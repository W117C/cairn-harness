# 第 60 页 · 波及清单是并集就要说并集：影响面的**假阳性**那一侧

日期 2026-09-25。基线 HEAD `5b551ec`。第 55/56 页补的是"漏报没说"（图外 ⇒ 未知），这一页补相反的一侧：
**多报了却不说是并集**。同一条政策的另一只脚。

## 一、实测：改一份定义，答案数进另一份的调用方

`map/parse.ts` 的 tag 只有 `def | ref` 两种（第 174、257 行），所以符号图**只按名字连边**。
两份互不相干的同名定义于是共享一张波及表。真跑（临时 worktree 外的一次性探针，用完即删）：

```
one.ts    export function run() { return 1 }      useOne.ts  import { run } from "./one"
two.ts    export function run() { return 2 }      useTwo.ts  import { run } from "./two"

impact_query {"symbol":"run"} ⇒
[impact] run 的定义在 2 个文件：跨文件调用点 2 处，波及 2 个文件
  useOne.ts: run(L2)
  useTwo.ts: run(L2)
```

我改的是 `one.ts` 那份，**`useTwo.ts` 与这次编辑无关**，但它出现在"波及"清单里，
而且没有一个字说这是并集 ⇒ 模型会去改它（多改 = 返工 + 无谓 diff）。
`{"file":"one.ts"}` 同一形状（走 `fileImpact`，它也 union）——这一格此前**没有任何用例**。

本仓有多大面积？把它加进第 59 页那把尺顺手量（两张图本来就已建好，不多花一次解析）：

```
同名多份定义的符号=240 / 图内符号共 3230
```

⇒ 全仓 **7.4% 的符号**是"别处还有一份"的名字。`run` / `main` / `test` / `assert` 这类恰恰最常出现在查询里。

## 二、归属做不到（诚实地说），所以自述 + 真出路

要精确回答"这份定义的调用方是谁"得采 import 并解析路径，而 tag 层没有这项信息 ⇒
**加 `ambiguousSymbols` 之后仍然不归属**，硬做会造出一个看起来精确、其实是猜的答案（比不知道更坏）。
出路只给真做得到的两件，写在句子内部：

```ts
export function unionNote(subject: string): string {
  if (subject === "") return "";
  return `（同名歧义：${subject} ⇒ 下面波及清单是**各份定义的并集**，本图只按名字连边、不认 import；` +
    "要收窄就先 grep 它的 import 确认归属，或按文件查 {file:…}）";
}
```

**第 51 页的规矩**：说"你可以 X"就必须用 X 那把工具真做得通——`grep` 与 `{file:…}` 都是模型手上就有的动作，
不指向不存在的开关。

真修法（**立任务待裁，不在本页做**）：`parse.ts` 采 import  specifier → 解析到 workspace 相对路径 →
图里加"引用文件 → 定义文件"这一维；代价是 `TAGS_EXTRACT_VERSION` 要 +1，
于是**每个文件的 tags 缓存全部作废重解析**（本仓实测一次全量解析 ≈1.2s，worker 侧按 worktree 各付一次）。
这笔钱值不值，交给 #42。

## 三、形状

* 一份实现两支共用（`symbol` 支 / `file` 支），deps 支**刻意不接**并署名：`downward` 报的是
  "我引用到的定义点"，每个定义点各自列出，不声称"波及" ⇒ 没有并集可混淆。
* 数据层新字段 `FileImpactReport.ambiguousSymbols`（与第 55 页的 `graphFiles` 同一族做法：
  读端要自述的东西必须由建图侧带出来，不然那一支永远说不出口）。
* 锚点约束照旧：被钉的 `return { ok: true, output: sitesNote(head, r.up) };` 一行**逐字未动**，
  自述一律拼进 `head`。`--check-needles` 前后同为阻断 6、钉在飞文本 2。

## 四、判卷与牙（先 RED 后 GREEN）

4 条新用例：两份定义（要"2 份定义"+「并集」+ 出路里有 `grep`）、三份定义（份数是真数出来的，
且**不许**同时出现"2 份定义"）、file 支同一格（先断言"波及 2 个文件"——把缺陷本身钉在用例里，
再断言自述出现，并点名是哪个符号歧义）、**反向哨兵**：单一定义时一个字都不许多。
RED 时 3 条按预期红、反向那条绿（它守的是现状不变）。

五格突变（跨两个源文件，逐字恢复 + 打印"两个文件恢复后均逐字一致 ✅"）：

| 突变 | 红 | 谁 |
| --- | --- | --- |
| U1 `subject === ""` 判据作废（恒说并集） | 1 | 反向哨兵 |
| U2 自述整段消失 | 3 | 三支正向全红 |
