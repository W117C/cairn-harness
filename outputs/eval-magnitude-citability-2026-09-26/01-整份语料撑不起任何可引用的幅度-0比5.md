## 一、判据长在哪里

`scripts/lib/eval-arms.ts`（纯函数）＋ `tests/eval-arms.test.ts`（10 → 26 条）：

- `magnitudeOfAb(组)` → `AbMagnitude{variants[], ratio, floor, minReps, minMeasured, verdict, reason}`。
  `verdict` 是**四态**（加一条结构态），每一态各管一种"这数不能当结论"：
  · `unreplicated`：本格每条臂可用样本 <2 次 ⇒ **没有自己的**噪声底；
  · `within-noise`：有底，但幅度 ≤ 底 ⇒ 与「重跑一遍」分不开；
  · `degenerate`：一臂一次 token 上报都没有 ⇒ 比值无定义（不读成 0× 也不读成 ∞）；
  · `citable`：只有这种允许引用倍率。
  另有 `not-ab`（组内只有一条变体＝重复组），它是**给重复行算底**的那一支，不产幅度。
- `signTestToken(mags)`：符号与幅度分开判。n=1 的配对支持"5/5 同向"，不支持任何倍率；
  分母、同值格、被剔除格三个数一起交出来（同值＝"没差异"的证据，≠证据缺席，所以不混进 `skipped`）。
- `abRowLine` / `repRowLine`：整行在库里拼，报告只 `console.log`。
  理由：**判词必须与数字同一行**才拦得住引用，而"同一行"这件事只能在字符串层面被用例钉住（规则 80）。

口径取最严的那一格：**噪声底只认「同一任务、同一条臂的重复」**。
第 89 页那个 3.34× 是 `ga-strategy/fanout` 自己的三次重复给的，它**约束不了** `loop-eval-v2/I1` 的 1.63×——
借来只会让一条读数看起来比它实际撑得起的更硬。这条"不许借"是本轮唯一一条反控用例专门钉的东西。

## 三、两条新尺各自造过一次红（不是注释里的承诺）

判据上线前，先在自己手上红一次：

1. 把"必须有同配置重复"那半边摘掉（`minMeasured < 2` 永假）⇒ **4 条用例红**，
   且正是 `unreplicated`／"借别格的底"／"每臂只跑一次仍不可引用"／"报告行自带资格" 这四条；
   `citable`、`within-noise`、`degenerate` 三条照旧绿 ⇒ 变异不是把整块判据打烂，而是**恰好放走了 n=1 那批格**——
   也就是第 89 页我拒绝引用它们的那个形状。
2. 把噪声底从「同变体内部」改成「整组极差」⇒ **2 条红**：
   `citable` 那条红（幅度自己把底撑大 ⇒ 4× 的效果被 4× 的"底"吃掉，判据变成永远不可引用），
   反控那条也红（`I1` 从别的臂借到了底）。
   这一支暴露出一个值得记的通用陷阱：**跨臂算抖动会把策略效应本身当成噪声**，所以"底"只能同臂取。

顺带被自己的用例/门抓到的三处（都已改）：
- 中位数原来取"上中位"（偶数样本取较大那个）⇒ 现在取真中位，且 `median` 做成 `VariantRep` 的字段：
  统计量没有观测者就等于没有（缺报当 0 参与中位会把一臂算便宜一倍，`I7` 那条用例钉的就是这个）。
- 报告行一开始把比值、每臂终态拆成两处印 ⇒ 收回库里一次拼好，并加一条"顺序也要钉"的断言
  （判词若印在数字之前，读的人先抄了数）。
- **改了 reason 文案却没再跑那条断言**：把 `unreplicated` 那句从"本格没有同配置重复"改成"不足两次同配置重复"之后，
  我只跑了别的文件，红是**主树全量门**抓出来的（`2505 passed / 1 failed`，唯一那条红的正是我自己留在盘上的）。
  同一跑里还有一层：那条命令接了 `| tail`，通知里的"exit 0"是 `tail` 的退出码 ⇒ **汇总行才算数**（老规矩，这次差点对自己失效）。
  ⇒ 这不是新病，是**规则 170 的复发**（"改文案会打瞎按旧措辞收料的读数面"）；本轮那句"写在散文里的口径等于没写"对我自己同样成立。

### 五之一、抄那句红的过程中，门自己露了一个洞（当场配对量过）

第一版我把那个登记项 id **原样抄进 PROGRESS 的那句"这不是我的红"** ⇒ `docs-check` 从 1 项红变 **0**。
去掉那串字符（意思一个字没动）⇒ 红又回来。两侧读数都在同一台机器、同一次会话里跑过。

读 `checkReplay` 才明白为什么：它的"有文档引用"判的是
`REPLAY_DOC_FILES`（`AGENTS.md`/`PROGRESS.md`/`STATE.md`）的正文里**出现过 `replay:<id>` 这串字符**——
一条否定式的记账句与一条教学式的复跑说明，在这把尺底下长得一模一样。
⇒ 登记项可以被**另一条线程的免责声明**永久垫绿，而真正该写复跑命令的那一页始终没写。

这一格与第 87 页那句同族：**"取料面未记 ≠ 没人垫"**——这里是反过来：**"被提到 ≠ 被引用"**。
本轮不修（`scripts/docs-check.ts` 与 `scripts/replay-readings.ts` 都在别人手里），立案 **#19**：
判据应要求"该 id 与那条复跑命令出现在同一段落里"，光有 id 不算。
现在我把 PROGRESS 里的写法改成不带 `replay:` 前缀的形式 ⇒ 对方的红留在原地，洞单独记着。

## 六、与那条线程的接缝（同一份语料，两个读数不冲突）

对方第 90 页把 token 差往下拆到"每请求的固定开销"，结论是**长提示贵在那一轮多跑了几次请求**，而提示本身只占输入的 8%。
这与本条不矛盾、而且互相要求：本条说的是"`1.63×` 这个倍率今天不许引用"，
对方说的是"若真要引用，得先按请求数拆开再比"——**幅度判据管资格，成本分解管成因**。
两条都在同一张 y 轴上：先别拿数当结论，再看那数由什么构成。
