# 切片边界的棘轮闸（2026-09-23）

写这篇的理由很直白：上一个工件（`outputs/renderer-demo-data-2026-09-23.md` §六）刚把
「改注释 = 改判卷取料面」记成规矩，**几分钟后我自己又写了一条**
（`tests/renderer-no-demo-data.test.ts` 里 `indexOf("/* 工作区列表有两个来源")`，提交前改成 `let realWorkspaceRows`）。
⇒ 写在文档与记忆里的规矩不约束手。这条要变成一道秒级的闸。

## 一、量的现状（探针：AST 扫 `tests/*.ts`，跑完即删）

- `tests/` 里字符串字面量共 **21634** 条，其中以注释标点（`//`、`/*`）开头的 **64** 条。
- 落在**切片调用**（`indexOf` / `lastIndexOf` / `slice` / `section` / …）参数位上的 **47 处**，
  去重后 **29 个唯一标记**，分布在 **21 个文件**。
- 剩下 **17 条不是病**：它们是喂给被测码的 fixture 文本（`docs-check` 举的病样、`prune` 的 `"// "`、
  `edit-file-hint` 的规则片段、`gym-rounds-e2e` 的 `"// x\n"`）。
  ⇒ 分界靠 callee 名筛，不靠豁免名单放行——否则正当用途得一条条写豁免，漏写一条就是假红。

## 二、判据形状

1. `scanCommentBoundaries(file, src)`（`scripts/assertion-health.ts`，纯函数 / AST）
   —— 与 `scanEmptyAsserts`、`scanDisjunctions` 同一族：**AST 而不是按行正则**，
   因为"注释里举的反例"会被正则当成代码（这一族本仓已自踩过，实测 3 条自命中）。
2. 观察面 = **git 已跟踪的 `tests/`**，复用 `trackedScriptFiles(ROOT, prefix)`。
   `prefix` 是新增的可选参数（缺省仍是 `scripts`），**没有**另抄一份 `git ls-files`：
   扫描面口径是本仓立过的"同一条判据各抄一份"的靶子（快路只判已跟踪、gates 走磁盘遍历，
   隔壁会话一个未跟踪探针就能把整张门表判红）。
3. 快路两条，成对：
   - **新写的标记 ⇒ 红**（`LEGACY_COMMENT_BOUNDARIES` 之外的一律拦）。
   - **清单里已不再命中的条目 ⇒ 红**（"这些标记已经迁完或随被测码删掉了，从清单里一并撤"）。
     只有上一条时，这份名单会在几次迁移后变成一堆读不出真值的装饰——比没有更坏，因为它假装在记账。
4. **按标记记账，不按文件**：文件级豁免会让"已经豁免的那个文件再加一条"静默通过
   （我自己这轮就是往一个已存在的测试文件里追加新判据的）。

## 三、造红两侧（新判据必须当场红一次，跑完即删）

`tests/renderer-collapse-single.test.ts` 是被借用的靶子，两次都 `git checkout --` 还原，还原后复跑绿。

**① 撤掉一条在用标记（模拟"迁完了但没删清单"）**：把 `indexOf('/* 折叠的唯一实现')` 换成代码标识，
只跑本文件 ⇒

```
FAIL tests/assertion-health-scan.test.ts > … > 反面对手：清单里已不再命中的条目必须删掉（豁免名单不许自己烂着）
AssertionError: 这些标记已经迁完或随被测码删掉了，从清单里一并撤：["/* 折叠的唯一实现"]: expected [ '/* 折叠的唯一实现' ] to deeply equal []
```
同一次跑里"不许新增"那条仍 ✅（正确地不响——撤走的是清单内的东西，不是新写的）。

**② 新写一条注释边界（tracked）+ 同形状写进一个未跟踪草稿**：
靶子文件加 `src.indexOf("/* 探针：新写的注释边界 */")`，未跟踪的 scratch 里加
`src.indexOf("/* 未跟踪草稿里的注释边界 */")` ⇒

```
FAIL … > 已跟踪的 tests/ 里不许新增注释文字当边界（边界一律用代码标识）
AssertionError: 新写的注释边界，改成 function 名 / const 名：["/* 探针：新写的注释边界 */"]: expected … to deeply equal []
```
**未跟踪那条不在数组里** ⇒ 一次跑同时证两件事：新写会拦，隔壁会话的草稿不会把我判红。
"反面对手"那条同跑仍 ✅（清单未被扰动）。

**③ 还原后**：`tests/assertion-health-scan.test.ts` + 靶子文件 22 条全绿。

## 四、这一轮没做的（留名）

   每支都得逐个核对区间等价（区间悄悄变小是静默通过的那种错）。清单已按标记点名，逐条删即进度。
2. ~~变异锚点没建~~ **同日下一笔已补**：`slice-boundary-scanner-blind`（尺子变瞎——认不出注释标记）与
   `slice-boundary-every-string-is-a-marker`（撤掉"以注释标点开头的才算"这道筛——fixture 文本全成标记），
   各钉不变量的一半，实测 `✅ 全部变异被正确杀死`（2/2、8.7s）。
   原记的"接线不调用那一格"其实由第一条观测：尺子不认 ⇒ 单元侧那条立刻红，故不再单列。
3. **`src/renderer/app.js` 里注释被当边界的"另一半"没管**：即某个切片标记指向的注释若本来就是
   写给读者看的说明，产品侧没人知道它同时是判卷针脚。要治得在注释侧留名字（或反过来要求边界
   用 `// gates:marker` 这类显式记号），那是另一个形状，未开工。
