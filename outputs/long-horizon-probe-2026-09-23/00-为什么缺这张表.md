# 00 为什么缺这张表：长时程回放（能力 11）· 2026-09-23

> 落地：`src/agent/gym/probe.ts` 的 `replayLongAssembly` / `diffLongReplay`，CLI `scripts/gym-long.ts`。
> 判卷侧：`tests/gym-long-replay.test.ts`（6 条）+ 4 条 `lr-*` 针脚。施工与读数在 `01-实测与回执.md`。

## 1. 缺口（本仓自己的原话）

`outputs/architecture-uplift-2026-09-21.md` 与新开的 BLOCKED 裁决 3 都记着同一件事：
**靶场三条 case 实测全是 `requests=1`** ⇒ 缓存命中、压缩触发、per-turn 回注、跨轮检索这些
**只在多轮生效**的机制在靶场内一次都触发不到，基线 `successRate:1 / 645 tokens` 是天花板——
任何 harness 改动在这里只能证明「不掉分」，不能证明「买到分」。

裁决 3 留了两条路：
- ① 新增一条 ≥10 轮的**冻结 case** ⇒ 要动 `fixtures/gym/cases/**` + `index.json`（判卷区，sha256 冻结）；
- ② **只给探针加放大重放，不动判卷文件**。

本能力走 ②。走 ① 之前需要用户裁决（改判据），走 ② 不需要——它加的是仪器，不是考卷。

## 2. 为什么这是「agent 共同的问题」而不是本仓私事

外部读数（同 `../model-surface-budget-2026-09-23/00-调研综述.md`）里最硬的一类全部是**多轮**现象：
- 《LLMs Get Lost in Multi-Turn》(2505.06120)：同一任务拆成多轮平均掉 **39%**；
- MTAC-IFBench (2609.14992)：指令遵循**随会话长度快速退化**；
- Anthropic context editing：100 轮评测里清掉过期工具结果/定义 **省 84% token**、配记忆工具 **+39%**；
- Manus：KV-cache 命中率是单一最重要指标（10× 价差），做法是 **append-only 上下文**。
一个 `requests=1` 的靶面对这四条**一个都测不到**。所以缺的不是再多几条短 case，
是**让同一条链能跑到第 N 轮**的那张表。

## 3. 表长什么样（每一列都是量出来的，不是估的）

```
轮   prompt      可缓存     易变sys        历史       头部存活        作废
45   89,325     8266         0        81,054       0.0%      422542
```
- `可缓存` = 首条 system + 工具规格（与 `classifyAssembly.cacheableBytes` 同层，不起第二个名字）；
- `头部存活` = **相邻两轮真正发出去的字节串比出来的 LCP / 上一轮长度**（复用 `compaction-cost.measureHeadSurvival`）；
  1.0 = 纯追加（缓存照旧命中），0.0 = 整段前缀作废；
- `作废` = 这一轮要重写进缓存的字符数——**`promptBytes` 里看不出来这一列**，这正是本表存在的理由；
- `压缩次数` = 事件流里真落的 `type:"compaction"` 条数（**认账证据**，与 `prefix-churn-check` 同一口径），
  与 `头部作废次数` 分开记，前者是「谁干的有凭据」、后者是「断了几次」。

## 4. 三条设计决定（都不是审美）

1. **增长的内容必须来自这条 case 自己的冻结剧本**。第一版我用 `"的".repeat(n)` 填，
   结果四条 case 量出**逐字相同**的表——看起来像仪器坏，其实是仪器没在读 case（见 `01` §3.1）。
   现在取剧本里的 `assistant_message` 正文 + `tool_call` 的名字与参数；
   **剧本没有可用正文就直接抛错**，宁可不量也不拿编造内容冒充某条 case 的读数。
2. **两个尺度分明**：`--scale small`（压小窗口，几轮内必压，用于回归/开发）与
   `--scale production`（128k 缺省窗口，要 ~40 轮才压一次，用于谈钱）。
   不标尺度的长时程读数没有意义——小窗口的「省 25.1%」在生产尺度上是「省 0.0%」（`01` §2）。
3. **只读 fixture，写只落临时目录**，并且这条被测例锁住（跑前跑后对 `fixtures/gym/cases/<id>` 取指纹比对）。

## 5. 明确不做

| 不做 | 理由 | 反转条件 |
|---|---|---|
| 把长时程读数接成**门**（第 36 道） | 它是仪器不是判据：数值随 case 剧本变，进门就成了漂移磁铁。判据已经有 `prefix-churn-check` 的 PC1–PC7（确定性、离线） | 出现需要长期盯住的阈值时（例如「作废字节数 > X」成为红线） |
| 用真模型跑长会话出「真钱数」 | 需联网凭据，属「未证 ≠ 通过」那一格 | 有凭据的环境里跑一次并落盘 |
| 让回放真的执行工具 | 那要起 sandbox/跑命令，测的就不是装配了 | 需要量工具执行成本时另立一格 |
| 造一条 ≥10 轮冻结 case（裁决 3 方案①） | 动判卷区，须先裁 | 用户批准换判据时 |
