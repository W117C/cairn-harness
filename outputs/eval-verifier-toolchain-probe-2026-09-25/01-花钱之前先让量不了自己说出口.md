## 一、缺陷：可行性判据数了快照与凭据，唯独没数"判卷命令跑不跑得起"

`src/agent/eval/task-set.ts` 的模块开头明明写着这条规矩——
> 可行性（缺仓库快照 / 缺凭据）与"跑出来是红的"必须是两种不同的读数：前者是**没有尺**，后者才是失败。
> 混起来就会把"0/529 可跑"读成"模型 0 分"。

但它只列了两支 blocker（快照、凭据）。而 SWE-bench 形态的判卷命令被适配层写死成
`python -m pytest -rA …`（`fromSweBenchJsonl` 里那一行）。本机实测：

| 检查 | 结果 |
| --- | --- |
| `which python3` | `/Users/ze/.local/bin/python3` ⇒ **在** |
| `python3 -c "import pytest"` | `ModuleNotFoundError: No module named 'pytest'` ⇒ **不在** |
| 改前 `feasibility()` 的返回 | 只要快照与凭据齐了就 `runnable: true` ⇒ **假绿** |

⇒ 光看可执行文件在不在，会得出"可以跑"；真跑起来 pytest 报的是**工具链缺失**，
而那条红长得**和模型没修对一模一样**（判卷非零退出）。这正是本仓在 `verify` 面上已经修过的同一族
（"包管理器自身报错 ≠ 代码失败"），只是换到了**评测面**，而评测面的输出是分数——**分数没有 cause 字段**。

## 二、修法：自检形状由纯模块推，spawn 留在调用方

```ts
deriveVerifierProbe("python -m pytest -rA t.py::u") === 'python -c "import pytest"';
deriveVerifierProbe("pnpm test")                     === "pnpm --version";
deriveVerifierProbe("./run_tests.sh")                === null;   // 认不出 ⇒ null，不编
```

- **`-m` 那一支是关键**：`python --version` 在这台机器上会成功，于是检查形同虚设；
  `-m` 缺的是**模块**，所以要探 `import pytest`。这不是抬杠——它就是本机的真实缺口。
- 复合命令（管道/`;`/`$()`）、带路径的脚本、`-m` 后面没有模块名 ⇒ 一律 `null`，
  由调用方按"跑不起来"处理。**宁缺不编**：编一条跑不通的自检等于再造一种假绿。
- `EnvProbe` 多一个 `canRunVerifier(task)`：纯模块不 spawn、不 IO（与文件头"为什么单独一支纯模块"一致），
  实装落在 `scripts/loop-eval.ts`（`spawnSync(shell, timeout 15s)`，**同一条命令只跑一次**，
  一批任务常共用一个 runner）。

## 三、改完的实机读数（零花费，`--feasibility` 一个模型请求都不发）

内置四条（判卷 `pnpm test`）：
```
[feasibility] 工具链自检 ✅ pnpm --version
[feasibility] 可跑 0 / 分母 4 …… ← 缺模型凭据（M0_API_KEY / M0_ENDPOINT）
```
⇒ 新检查**不误伤**能跑的那批（这条就是"反向不许恒红"的证据）。

喂一条 SWE-bench 形态实例（判卷 `python -m pytest`）：
```
[feasibility] demo-1  不可跑 ← 缺仓库快照 a/b@cafe1234…；
              判卷命令在本机跑不起来（工具链缺失：python -m pytest -rA t.py::test_x）⇒ 属未证，不许计成 0 分；
              缺模型凭据…
[feasibility] 工具链自检 ❌ python -c "import pytest"
⇒ 1 条任务全部不可跑 ⇒ 基准读数无从谈起，先看 blockers 里缺什么
```
**改之前这一条只会报"缺快照 + 缺凭据"**，快照一 fetch 就变成"可跑"——然后把工具链缺失花成一笔真钱和 0 分。

## 四、于是 #13 的"欠什么"从三格变成明确的四格（这才是这页的目的）

1. **快照**：`eval-snapshots/<instance_id>` 需要预先 fetch（本模块不联网、不 clone）；
2. **工具链**：本机没有 pytest ⇒ 要么装（`pipx`/`venv` 一次），要么先只跑 **JS/Go/Rust 侧**的任务集；
3. **凭据**：`M0_API_KEY` / `M0_ENDPOINT`；
4. **裁决**：跑不跑（真钱）——这一格仍然只能你拍。
前三格现在都由同一条 `--feasibility` 免费读数说出口，**不需要花一分钱就知道会不会白跑**。
