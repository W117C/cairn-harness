## 二、打开方式

**双击 `forge-ui-v3.html`** 即可在任意现代浏览器（Chrome / Edge / Safari）中打开，无需安装依赖、无需启动服务、无需联网。

### hash 锚点（直达初始态，可组合，逗号分隔）

在地址栏文件路径后追加 `#锚点`：

| 锚点 | 作用 |
|---|---|
| `#tasks` | 直达「任务执行」视图 |
| `#history` | 直达「历史」视图 |
| `#conversation` | 直达「对话」视图（默认） |
| `#dark` | 深色主题 |
| `#light` | 浅色主题 |
| `#cmdk` | 打开 ⌘K 命令面板 |
| `#archived` | 展开侧栏「已归档」分组 |

## 三、可交互清单（真实可点）

- **排队发送**：composer 输入后回车 / 发送按钮，消息进入队列
- **停止中断**：运行中 composer 变为「停止」，点击中断当前运行
- **引用回填**：消息上的引用按钮，把该消息回填到输入框
- **卡片过滤**：对话上方「计划 / diff / 工具 / 审批 / verify / 报告」芯片，按卡片类型过滤
- **回到底部**：消息流滚动后出现「回到底部」按钮
- **卡片折叠**：plan / diff / tool / verify / report 卡片点击头部展开折叠
- **plan 批准 / 拒绝**：plan 卡底部的「批准 / 拒绝」
- **审批批准**：审批卡（approval）的批准 / 拒绝
- **任务视图切换**：顶栏「对话 / 任务执行 / 历史」切换
- **worker 事件流下钻**：任务视图点击 worker 节点，弹出该 worker 事件流 Sheet
- **worker 卡死恢复**：卡死节点旁的「恢复」按钮
- **run 批次展开**：历史视图点击 run 行展开产出详情
- **时间轴切粒度**：历史视图「列表 / 时间轴」切换 + 日 / 周 / 月 粒度
- **检索**：侧栏搜索框
- **状态筛选**：侧栏状态芯片（全部 / 成功 / 失败 / 被拒 / 已中断 / 进行中）
- **归档展开与恢复**：侧栏「已归档」分组展开、会话恢复
- **回收撤销**：删除会话后的撤销
- **主题切换**：⌘K 内「切换主题」或顶栏入口
- **⌘K**：命令面板（Mac ⌘K / Win Ctrl+K）
- **分隔条拖动**：左/右面板分隔条拖动调宽，双击恢复默认

## 四、已知占位（如实声明）

以下为**结构占位或未接线**项，非缺陷隐藏，特此声明：

1. **会话点击不切换消息正文**：点击侧栏其它会话，标题高亮会变，但右侧消息正文仍是同一份单会话内容（原型只内置了一份会话内容）。
2. **diff → 文件树的深层自动联动未接线**：只实现了显式按钮「在文件树中查看」的定位高亮，未实现 diff 行级 → 文件树节点的自动联动。
3. **run 聚合数据为前端结构占位**：任务视图 / run 历史依赖「一次运行」的聚合字段（worker 产出 / verify / diff 汇总），当前为前端写死的结构占位，**需内核补 run 聚合接口后接线**。
4. **依赖链连线端点为近似**：worker 依赖链的 SVG 连线端点按列中心估算，flex 布局高度可变时为近似；已用 `aria-describedby` 文字（「依赖：worker-1, worker-2」）兜底，不单独依赖图形表达依赖关系。
5. **原型为纯 HTML，不覆盖以下验证**：
   - **不含** Electron 窗口最小尺寸约束（960×600 属 `src/main/index.ts`）；
   - **不含**真机屏幕阅读器播报验证；
   - **不含** 4K / 150% 系统缩放验证。

## 五、落地提示

- 本原型的**落地对象**是 `src/renderer/index.html`（内联 CSS）+ `src/renderer/app.js`（vanilla 层），**不是**未接线的 React 版。原型只保留了 vanilla 层真实存在的钩子，**未伪造任何 `data-m1e-*`**。
- ⚠️ **`pnpm panels-check` 的 7 个 CDP 探针当前指向已断链的 React 层**，在当前工作树上**不可能全绿**。这属迁移未收口的遗留债，**需先裁决处置**，详见 `05-diagnosis-and-plan.md` §5.1：
  - 方案 A（推荐，成本低）：把 7 个探针改指 vanilla 层真实钩子；
  - 方案 B：把 React 层接线回来（等于放弃已完成的 vanilla 迁移）。
- 为迎合探针而伪造 `data-m1e-*` 钩子会制造**假绿**，比红门更糟，原型已刻意规避。

## 六、跨断点行为说明（取舍记录）

为避免残留态造成视觉/可达性错乱，**跨断点切换时折叠态按目标断点默认值重置，不保留手动折叠**：

- 在 ≥1024 宽下手动收起右板后，缩小到 ≤1023：右板会重新按覆盖式断点默认值**收起**（覆盖式 Sheet 在窄屏默认关闭）。
- 在 ≤1023 宽下手动打开覆盖式 Sheet 后，放大到 ≥1024：右板会重新按非覆盖断点默认值**展开**（三栏布局中右板常驻）。
- 同步刷新 `data-drawer` 与 `#drawerToggle` 的 `aria-pressed`，避免按钮与视觉不一致。

该取舍由审查官建议并已落实于 `forge-ui-v3.html`（resize handler 增加 `prevOverlay` 跟踪，初始化时按 `isOverlay()` 对齐状态）。代价：用户手动展开过的覆盖式 Sheet 在跨断点时会被收齐——属低风险，因为宽度变化是低频事件。
