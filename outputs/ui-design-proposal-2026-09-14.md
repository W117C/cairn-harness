# 桌面端 UI 设计方案（2026-09-14）

> **⚠️ 风格层已被 v2 取代**：`outputs/ui-design-v2-codex-style-2026-09-14.md`（基于 Codex 桌面端 9 张参考截图）。本文档的布局骨架（四区+状态栏、断点策略、最小窗口）继续有效；配色/组件形态/页面分工以 v2 为准。

> 定位：与性能优化报告配套的 UI 设计提案。原则——**演进而非推翻**：现有界面（shadcn/ui radix-nova + Tailwind 4 + Geist + oklch 中性色板）已具备完整设计令牌与 29 个组件，本方案在其上做结构化补全（顶部导航栏、自适应断点、核心页面组件规范），全部可增量落地。

## 1. 设计基线（沿用现有，不新增风格）

| 令牌 | 现状值 | 说明 |
|---|---|---|
| 字体 | Geist Variable（`styles.css:4,10`） | 全文统一；等宽场景（代码/diff/日志）用 `ui-monospace` |
| 色板 | oklch 中性灰阶（`:root`/`.dark`，`styles.css:51-118`） | 无品牌彩色，靠灰度层级；语义色仅 `destructive` 红 |
| 圆角 | `--radius: 0.625rem`（10px），派生 sm/md/lg/xl | 卡片 lg、按钮 md、徽标 sm |
| 主题 | light / dark / 跟随系统（`theme.ts:24-44`） | `.dark` class 切换；默认跟随系统 |
| 组件库 | shadcn radix-nova preset，29 个本地组件 | 改生成组件需标 `// @shadcn-modified` |

**信息层级总则**：背景 `<` 卡片 `<` 面板 `<` 弹层（Dialog/Popover）`<` Toast；文字三级——正文 `foreground`、次级 `muted-foreground`（时间戳/元数据）、弱化 50% 透明度（占位/禁用）。危险操作恒用 `destructive`，可逆操作用 `secondary`。

## 2. 整体布局结构（目标信息架构）

现状：系统标题栏 + 左 Sidebar（`collapsible="icon"`）+ 主区 68% / 右面板 32% 可拖双栏（`main.tsx:1211-1441`），**无全局顶部栏**。

提案：四区 + 状态栏的单窗口工作台（SPA 不引路由，"页面"由侧栏导航 + 右侧面板组合表达）：

```
┌────────────────────────────────────────────────────────────┐
│ 顶部导航栏 h-10 (40px) · frameless hiddenInset 标题栏          │
│ [≡ 侧栏] [会话名/页面名]      [运行状态●] [面板开关] [🌓] [⚙] │
├──────────┬──────────────────────────────────┬──────────────┤
│ 左侧栏    │ 主内容区（会话工作台）              │ 右侧面板      │
│ 240px    │ 弹性，min 480px                   │ 320px/32%    │
│ 可收 64px│ 横幅→消息流→输入区                 │ 8 面板切换    │
│          │                                  │ 可拖可关      │
├──────────┴──────────────────────────────────┴──────────────┤
│ 状态栏 h-6 (24px) · 沙箱徽标/事件数/tokens/调度器              │
└────────────────────────────────────────────────────────────┘
```

**落地映射**（尽量小改）：
- 顶部导航栏：BrowserWindow 改 `titleBarStyle: "hiddenInset"`（macOS 红绿灯内嵌），中栏现有 header（`main.tsx:1344-1348`）上移为全局顶栏，注入运行状态徽标与右面板开关（现分散在侧栏「运行状态」组和右板头部）。
- 左侧栏：保留现有 Sidebar 组件与 240px/icon 64px 双态；导航分组改为「会话 / Agents / 定时 / 记忆」四组（后三组现仅存在于右板，提升为一级导航入口，点击 = 打开对应右面板并定位）。
- 状态栏：新增 h-6 底栏，收纳现侧栏「运行状态」组的沙箱徽标/事件数/tokens（`main.tsx:1303-1324`），常驻可见不占侧栏高度。

## 3. 分辨率与窗口自适应

### 3.1 目标分辨率

| 档位 | 分辨率 | 占位的布局策略 |
|---|---|---|
| 小 | 1280×800（13" MBA） | **基线**：三栏齐全，左栏 240px、右板 32%≈330px |
| 中 | 1440×900 / 1920×1080 | 舒适档：全部默认比例，消息流 max-w 居中 |
| 大 | 2560×1440 | 比例制生效，右板不超 480px（`maxSize` 已由 70% 改固定 px 上限） |
| 4K | 3840×2160 | 布局同大档 + Electron `webFrame.setZoomFactor` 整 UI 缩放（设置项：100/125/150%），避免字阶碎片化 |

### 3.2 窗口宽度断点（resize 自适应）

| 窗口宽 | 行为 |
|---|---|
| ≥1600px | 三栏全开；消息列内容区 `max-w-3xl` 居中，两侧留白，长行不拉伸 |
| 1280–1599px | 默认布局（现状即此档） |
| 1024–1279px | 左侧栏自动坍塌为 icon 态（64px）；右板保持 |
| 800–1023px | 右面板改**覆盖式 Sheet**（复用现有 `sheet` 组件，从右滑出遮罩主区），不再挤压主内容；审批卡到达时 Sheet 自动弹出 |
| <800px | 不允许：窗口最小尺寸锁定 **960×600**（BrowserWindow `minWidth/minHeight`，现状未设） |

关键规则：
- **栏宽持久化**：`settings.layout` 已存右板宽度，扩展存左栏态（展开/icon）与窗口 bounds；自适应切换不覆盖用户手动拖出的宽度（手动 > 自动）。
- **主区保护**：任何断点下主内容区 ≥480px，输入区永不折叠。
- **消息流**：bubble 最大宽 85%，diff/表格卡片横向 `overflow-x-auto`，竖向滚动态归 react-virtuoso。
- **面板切换自适应时不丢状态**：Sheet 化只是容器替换，面板组件与 REGISTRY 不变。

### 3.3 窗口状态

- 记住 bounds + 最大化态（退出时写 settings，启动恢复）。
- 全屏（macOS native fullscreen）：顶栏保留（hiddenInset 天然适配），左右栏不变。

## 4. 核心页面：组件构成与交互

### 4.1 会话工作台（主页面，默认落地页）

**构成**（自上而下）：
1. **顶栏**：SidebarTrigger + 会话名（双击重命名，复用现有重命名交互）+ 右侧运行状态点（灰=空闲/绿脉冲=运行中/红=错误）+ 面板开关组 + 主题 + 设置。
2. **横幅区**（条件渲染，现状已有 `main.tsx:1349-1362`）：错误 / 沙箱降级 / license 提示，统一样式为 `border-b` + `bg-muted/50`，可关闭但 license 类不可关。
3. **消息流**（react-virtuoso，现状正确）：
   - 气泡：`UserBubble` / `AssistantBubble`（markdown 纯文本 pre-wrap）。
   - 工具行 `ToolRow`：工具名 + 状态点 + 摘要一行，点击展开详情。
   - **10 类卡片**（`cards/registry.tsx:201-212`）统一卡片骨架：`Card` + 头部（图标+标题+时间）+ 内容 + 可选操作区。其中——
     - `approval` 审批卡：**四钮层级** = 主钮「批准一次」(primary) → 次钮「本会话放行」(secondary) → 弱钮「永久放行」(ghost+警示色 hover) → 危险「拒绝」(destructive outline)。永久放行是写盘操作，必须二次确认 Popover。
     - `diff`：文件头 + 行级增删色（绿/红 10% 透明度底，不用纯色，保持灰阶体系内辨识度）+ 行级评论入口。
     - `plan` / `verify_result` / `report`：左侧 2px 竖条语义色标（plan=foreground、verify 通过=绿、失败=destructive）。
4. **输入区 footer**：Textarea 自适应 1–8 行；Enter 发送 / Shift+Enter 换行；发送钮运行中变停止钮；左侧 + 号（附件/引用文件，复用 `attachment` 组件）。
5. **空态**（`empty` 组件）：图标 + 一句引导 + 三个快捷动作（新会话/打开示例/查看定时任务）。

**交互要点**：流式期间输入区保持可输入（排队发送）；「回到底部」浮钮仅在上滚时出现；审批卡到达时顶栏状态点转黄脉冲 + Dock badge（macOS）。

### 4.2 Agents 编排（右板 → 可提升为一级视图）

- **右板形态**（现状 `registry.tsx:898`）：worker 卡片列（名称/状态点/最近事件一行）+ 取消钮；头部「合并控制塔」入口。
- **一级视图形态**（提案，窗口 ≥1280 时从右板拖出或导航组点击放大）：主区替换为 pipeline 图——节点 = worker（复用 `agent_card`），边 = 依赖链；点击节点右侧滑出该 worker 的事件流。合并控制塔固定底部条：待合并 worktree 列表 + 合并/丢弃操作（危险操作二次确认）。
- 状态色纪律：运行=绿脉冲、等待=灰、卡死=黄、失败=红；**不新增色相**（chart-1..5 灰阶区分多条 worker 线）。

### 4.3 定时任务（右板三态）

列表态（任务卡：名称/cron 人性化描述「每天 09:00」/下次运行/启停 Switch）⇄ 表单态（名称、prompt、频率预设下拉「每小时/每天/每周/每月」+ 自定义 cron 折叠项、生效区间）→ 历史态（运行记录行：时间 + 成败徽标 + 摘要）。无人值守任务卡加「自动」徽标（fail-closed 语义 tooltip 说明）。

### 4.4 记忆（右板）

两层快照（长期 MEMORY / 当日日志）分 Tab；每条记忆 = 文本 + 时间 + 删除（destructive ghost 钮，二次确认）；底部「审计」折叠区列写入记录。与 sidechat「提升为记忆」动作联动（toast 确认）。

### 4.5 设置（模态 Dialog，现状七组保持）

Provider / 权限 / UI / 定时 / 记忆 / 成本闸 / 遥测 / 关于。改动仅两处：① UI 组新增「界面缩放 100/125/150%」（§3.1）；② 组导航从纵向堆叠改左侧 Tab 列（Dialog 宽 720px 时），每组内容独立滚动。

### 4.6 引导（4 步 Dialog，现状保持）

步骤点 + 每步一图一文一主钮；末步「打开示例会话」直接落到工作台空态快捷动作，闭环。

## 5. 交互与可用性规范

### 5.1 键盘快捷键（新增全局层，现几乎为零）

| 键 | 动作 |
|---|---|
| ⌘N / ⌘W | 新会话 / 关闭当前会话 |
| ⌘B / ⌘J | 切左栏 / 切右板 |
| ⌘1…⌘8 | 直达 8 个右侧面板 |
| ⌘K | 命令面板（会话搜索 + 动作，复用 `dialog`+`input`，顺带补上侧栏缺的搜索能力） |
| ⌘, | 设置 |
| Esc | 关弹层 / 停止运行 |

菜单栏注册（Electron Menu）使快捷键可发现；全部在顶栏 tooltip 与 ⌘K 面板内标注。

### 5.2 反馈与加载

- 发送后 300ms 内出 AssistantBubble 骨架（`skeleton` 组件），首 token 到达即替换。
- 所有写操作（删会话/删记忆/丢弃 worktree）：destructive + 二次确认 + 成功 Toast（可撤销 5s 的为优，如会话删除先进回收态）。
- IPC 失败统一横幅 + 重试钮，不静默。

### 5.3 无障碍与易用

- 全界面 Tab 可达；审批卡打开时焦点自动落入主钮（Enter=批准，但不绑死——`autoFocus` 仅聚焦不激活，防误触）。
- 状态不单独依赖颜色：运行态同时有「脉冲动画 + 文字」（动效遵循 `prefers-reduced-motion` 降级为静态点）。
- 最小点击区 28×28px（侧栏项/面板头钮）；tooltip 延迟 400ms。
- 对比度：现有 oklch 灰阶在 light/dark 均满足 WCAG AA（正文 >7:1，次级 >4.5:1），新增语义色须同检。

## 6. 实施优先级（与性能报告节奏对齐）

| 级别 | 项 | 说明 |
|---|---|---|
| P0 | 窗口 minWidth/minHeight、右板 px 上限、消息流 max-w-3xl | 纯配置/类名级改动，当天完 |
| P0 | 状态栏落地（迁移侧栏运行状态组） | 小改，立刻释放侧栏空间 |
| P1 | 顶栏化（hiddenInset + 全局 header 上移）、快捷键层 + ⌘K | 结构改动，需 panels-check 回归 |
| P1 | 断点自适应（1024 左栏坍塌 / 800 右板 Sheet 化） | 容器层改动，面板组件零侵入 |
| P2 | Agents 一级视图、设置 Dialog 分栏、撤销 Toast | 体验增强，独立迭代 |

**验证纪律**：布局类改动属 renderer 域，回归走 `pnpm panels-check` + `pnpm gates`；自适应断点需补 panels-check 的窗口尺寸断言（960/1280/1920 三档截图比对，复用现有 panels-check 截图基建）。

## 7. 明确不做的

- 不引路由/多窗口：单窗口 SPA + Sheet/Dialog 已覆盖全部页面诉求。
- 不换字体/色板/组件库：风格一致性优先于新鲜感。
- 不做毛玻璃/渐变等装饰：与灰阶工程感定位不符，也省渲染开销（呼应性能报告 U 系列）。
