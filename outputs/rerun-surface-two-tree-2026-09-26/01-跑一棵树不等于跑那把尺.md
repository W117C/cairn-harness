## 三、第一格（我的账）：`drift「30000」` 是这把尺的假红灯，且只有干净树看得见它

真形状（逐字取自两侧）：

```
生产：kept.push({ … detail: `；存量水位 ${String(wa.upTo)}（超出即新增违规）` })
判卷：const d = waive(over(30_001), w(30_000)).kept;
      expect(d[0]!.detail).toContain("水位 30000");
```

`staticRuns("水位 30000")` 切成 `水位` ＋ `30000`：`水位` 在生产侧**抽得到**，缺的那半是**测试自己给的整数**。
而第五态 `echo-caller-text` 的料是 `suppliedInTest`＝「整串字面量在本 test 文件里另有的一处」——
`30_000` 与 `"30000"` 是同一个数、不是同一个字面量 ⇒ 整串永远只出现一次 ⇒ 旧写法只能落进 `drift`，而 drift 是**红**。

为什么第 113 页那轮没看见：主树里 `scripts/docs-check.ts` 与 `tests/docs-check.test.ts` 都是 `M` ⇒ 这条被
「在飞，不计我的账」按住了。**跑一棵树等于只跑了半个判卷面**（规则 58 的新变体：不是"跑邻域≠跑那道门"，
而是"跑一棵树≠跑那把尺"）。

修法（`scripts/prose-needle-scan.ts`，我名下、干净文件）：新纯函数 `onlyTestSuppliedIntegers(missing, testText)`，
只在**缺的段全部是纯整数、且该整数以同值字面量出现在同一个 test 文件里**时把这条归进 echo。三处收紧写在注释里：
小数/带单位的段（`0.1`、`ms`）一律不收；散文段没见证时不收（`seen.size > 0` 是前置）；被断言的数值格式真变了，
**vitest 自己会红**——那条断言是真跑的，本尺只管"文案字面量漂了没人改断言"，不替运行时断言记账。

见证（三态齐全，规则 46）：

| 跑法 | 改前 | 改后 | 摘掉新判据（M1） |
| --- | --- | --- | --- |
| HEAD 树 `prose-needle-scan` | exit **1**，`echo 3 ｜ drift 1` | exit **0**，`echo 4 ｜ drift 0` | exit **1**，`echo 3 ｜ drift 1`（逐字同改前） |
| 主树 `prose-needle-scan` | exit 0，`echo 3` ＋ 那条 `⚠️ drift(在飞)` | exit 0，`echo 4`、在飞 drift 消失 | —（主树按住它，所以主树**证不了这一格**） |
| `tests/prose-needle-scan.test.ts` | 52 passed | **56 passed**，exit 0 | **2 failed｜54 passed**：`⑤b …⇒ echo，不是 drift` 与 `onlyTestSuppliedIntegers 的取值域…` |

M1 的写法与还原：`return false; // M1 造红：临时废掉新判据（跑完即删）` 插在函数第一行（Edit 单点，不用脚本切片），
`cp /tmp/pns-116.bak` 复原，`grep -c "M1 造红"` 两棵树都 **0**，`diff` 与备份**逐字节一致**，`git diff --numstat` 回到 `44 0 / 44 0`（纯新增）。

诚实标注（规则 129/106）：新增的四条里**只有 ⑤b 正格与取值域那条是复现器**——两条反向格（生产改成千位分隔、
散文段压根没见证）在旧规则下**本来也绿**，它们防的是"以后把 echo 放宽成逃生口"，不是本轮的复现器。
本轮的复现器是「HEAD 树 exit 1 → 0」那一次真跑。

## 四、第二格（别人的账，但会在 HEAD 留红）：D-8 的「没有文档引用」是别人那笔未提交的新增

逐条取证，不靠猜：


⇒ 这条红**不是**桌面层删除造成的，而是**新增侧**：有人往登记表加了一项 `replay:prompt-fixed-cost`，
而引用它的那几页全住在 `outputs/`（D-8 面外）。今天它只在盘上红；**那笔一旦提交就变成 HEAD 的已提交红灯**，
形状与第 83 页那 3 条一模一样。归因用序列事实而不是"应该不是我"（规则 120）。

本面欠的那一格（不在本轮做，理由见第六节）：D-8 那句「没有任何文档引用」应当同时印出**它查过哪些页**，
