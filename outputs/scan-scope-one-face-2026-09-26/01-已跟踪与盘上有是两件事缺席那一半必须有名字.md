## 一、四份副本，宽度不同：差的不是谓词，是"缺席有没有名字"

同一条口径（`trackedScriptFiles` ＋ `existsSync`）在仓里有四支：

| 调用方 | 缺席那一半 | 今天的实际后果 |
|---|---|---|
| `scripts/gates.ts` | 打 `gone` 清单（"跳过但不静默"） | 报告诚实 |
| `scripts/probe-promise-recall.ts` | `missingOnDisk` 字段 ＋ 头行印数 | 报告诚实 |
| `tests/promise-recall-inventory.test.ts` | 抄探针那份，同样是字段 | 报告诚实 |
| `tests/assertion-health-scan.test.ts:36 / :141` | **`.filter(existsSync)` 静默丢** | 判卷面 86→71、276→225，仍写着"扫已跟踪脚本" |

静默那一支恰好是**唯一"范围缩小不会响"的那支**：它有两道下限（`> 10`、`> 50`），
而 51 个文件的缺席只把 276 推到 225——下限断言防得住"清零"，防不住"比例级收缩"（规则 82 的新变体）。

## 二、收成一份

`scripts/lib/scan-scope.ts` 新增 `trackedExistingFiles(cwd, prefix)`，交三个字段：

```ts
{ files: string[]; missingOnDisk: string[]; trackedUnavailable: boolean }
```

第三态是必要的，不是装饰：原来两支写 `trackedScriptFiles(...) ?? []`，把"拿不到 git 清单"读成"没有要扫的东西"＝fail-open。
现在调用方必须自己决定退回磁盘遍历还是红（`gates.ts` 退回并出声；探针靠"清单为空＝没有尺"那条已有守卫）。

迁了三家（`gates.ts`、`probe-promise-recall.ts`、`promise-recall-inventory.test.ts`）。
**第四家没迁**：`tests/assertion-health-scan.test.ts` 的那两处 `.filter(existsSync)` 在**别人的在飞 hunk** 里
（正是那笔 hunk 加进来的），按"桌面层删除由原作者自己入库"的规矩我不动，改法与连带账已写进 #12。
