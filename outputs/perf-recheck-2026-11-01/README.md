## 结论修正（第 956 页）

第 955 页只跑了两跑（310.6 / 270.1），据此写「启动约 2×」，把 10-27 的**单点** 153.3 当基线。
补到五跑后：**188–312 ms、中位 270、离散度 1.66×**——「翻倍」不成立。能说的只有：启动比 10-27 的单点高，
但五跑离散度本身已接近 2×，单点对比不足以判定趋势。确定性读数（DOM +8.1%）不受影响。
`docs/REPOSITORY-STATUS.md` 那一行已按五跑改写；判据加了一条「性能行必须写区间 + 中位」。

## 边界

- 合成 AgentApi + 合成流式增量：量的是 renderer 生命周期与 DOM，**不是**模型吞吐或计费。
- 五跑同机、期间还有别的会话在跑；用于趋势对照，不当作认证。
- `performance-smoke.cjs` 的预算可用 `CAIRN_PERF_*_BUDGET_MS` 覆盖；本轮用默认值。
- 4000 行 diff 挂载（191.1 ms）与 FilePane 500 项 smoke 本轮没重量。
