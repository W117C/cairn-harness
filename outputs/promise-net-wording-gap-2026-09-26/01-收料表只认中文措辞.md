# 第 70 页 · #58：回取承诺的收料表只认五种中文措辞 —— 英文写法整族漏收，量出来的规模是 222 : 2

来路：第 63–65 页那把尺（`probe-promise-recall` ＝ AST 只收清单、逐面真跑"最后一跳"才出判定）。
第 69 页给截断提示补"下一步"时我想到一件事：**这张网是按措辞收料的**，那换一种语言写承诺还收得到吗。

## 量尺（一次性，跑完即删）

对 `src/` 已跟踪文件做 AST 扫描，收"模型可见文本里点名一个可调用工具"的字符串：

| 读数 | 数量 |
| --- | --- |
| 点名可调用工具的模型可见串（去重） | **222** 格 |
| 其中被原措辞表（5 种中文说法）收到的 | **2** 格 |
| 真的是"照这句做就能取回原文"的漏网面 | **2** 格 |

那 220 格绝大多数不是承诺：工具 schema 自身的描述、`switch` 的键、`../verify` 这类 import 路径、错误串。
⇒ **不能一律当承诺**（第 63 页就是手抄措辞表漏收，反向的错是把散文当承诺，规则 164 已踩过一次）。
真漏收的两格是：

- `src/agent/ledger.ts#project`：`[observation <id>: N bytes, M lines; obs_recall available]`
- `src/agent/solpi-runtime.ts#candidate`：`[…; 取全文 obs_recall id=<id>]`

两处承诺的都不是"再等一次"而是**一个按开关注入的运行时工具**（`INJECTED_TOOLS.obs_recall.workerReachable=false`），
而这两格此前从没被判过"照那句真做一遍能不能取回"。

## 修法（收料加宽 + 判定补齐，同一原子簇）

1. `PROMISE_MARKS` 加 `" available"`（带前导空格，为了不把 `archive unavailable` 那种反向陈述收进来）与 `"取全文"`。
2. **弱标记必须合取**：`" available"` 单独不成承诺——同轮实测假红在
   `glm-session.ts` 的 `[context_budget_exceeded] … available 4321; request not sent`（一句容量说明）。
   于是加规则：命中弱标记的那一句还必须**点一个可调用的工具名**；工具名取两份事实源
   （`TOOL_NAMES` + `INJECTED_TOOLS`），不在这里抄清单（规则 64/122）。加宽后清单 7 → 9，FP 归零。
3. 两个新面各配一条 `RUNNERS` 判定，量法同一把尺：**把句子里那个 id 真拿去调 `obs_recall`**，
   再看回来的页里有没有原文凭证（走 shipped：`ObservationLedger.capture/project` +
   `createObservationRecallTool`；solpi 那格走 `SolpiRuntime.project` 跑满 `FULL_SENDS` 让收据支真发射）。
   两格都判 ✅，并在读数里写死可达性边界：`worker 可达=false ⇒ 这句只对主会话兑现`。
4. `tests/promise-recall-inventory.test.ts` +3 条：两种新写法都进清单且当场欠判定；
   **负控**——那句容量说明必须不收；盘上两格确实进了模型面清单（合成样本过了而盘上没收＝等于没修）。

⇒ 本轮**没有产品缺陷可修**：两格的承诺都兑现得了。收获是"这张网的漏收规模第一次有了数"，
以及两面从「没判过」变成「判过且为真」。

## 两条环境/判据教训

- **`mkdtemp` 在 macOS 落在符号链接根下**（`/var → /private/var`），而 ledger 全程 `O_NOFOLLOW`
  ⇒ `capture` 直接 `ELOOP`，第一版两条 hop 都红着报"这句承诺在这一刻根本不会发"。
  改 `realpath(tmpdir())` 后两格转绿。⇒ 判红先排环境（规则 52/89 同一格）；
  我把 `capture.error` 印进读数，正是为了这种时候一眼看出是环境还是产品——**没印的话我会去改产品**。
- **加宽判据的那一轮必然自造 FP**：`" available"` 无约束时把错误串收成了"新面"。
  当场收窄成合取并把那条形状固化成负控用例（第 68 页同形，规则 167）。
