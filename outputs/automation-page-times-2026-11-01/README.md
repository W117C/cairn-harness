# 定时任务页的两处小账 · 2026-11-01

检查起点与交付面都是共享工作树，HEAD `be9c0be5`；本批改动未提交。

## 这一批改了什么

1. **时间两种写法**：运行历史把 `due_at` 的原始 ISO（`2026-11-01T03:00:00.000Z`）直接摆上屏，而同一页
   任务的「下次」用的是 `toLocaleString`。改成两个都走 `fullTime`（本地 `YYYY-MM-DD HH:mm`，解析不了原样返回）。
2. **静默截断**：历史只铺 20 条，但标题只写「运行历史（N 条）」——25 条时列表到第 20 条就停，尾部被当成整份。
   改成一个常量 `HISTORY_SHOWN` 管铺多少条，超出时标题写明「· 只显示最近 20 条」。

## 边界

- 只统一「页面上怎么显示时间」，不动调度器落盘的 `due_at`（ISO 是事实源，界面负责读）。
- 20 条这个数是页面铺多少，不是历史保留多少；更早的记录仍在 `journal.jsonl` 里。
- 时区显示是本机时区；任务自己的 `timeZone` 已在抽屉副标题里写明（`scheduleLabel · 时区 …`）。
