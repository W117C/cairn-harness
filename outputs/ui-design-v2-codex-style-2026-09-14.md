# 桌面端 UI 设计方案 v2 · 参考风格融合版（2026-09-14）

> 基于 9 张 Codex 桌面端参考截图（主窗口/账户菜单/设置页/输入区/强度滑杆/附件菜单/权限菜单/右侧面板/定时任务/安全页）拆解其设计语言，并融合进本项目设计规范。**本文档取代 v1 的风格层**；v1 的布局骨架（四区+状态栏、断点策略）继续有效，冲突处以本文档为准。

## 1. 参考设计语言拆解

### 1.1 整体布局
- macOS 无边框窗口：红绿灯按钮内嵌（hiddenInset），顶栏左侧 = 侧栏开关 + 前进/后退，中部悬浮 CTA 胶囊（"重新加入 Plus" 紫色 pill），右侧 = 面板开关组。
- **持久左侧栏**（约 230px）：顶部应用名下拉 + 搜索/通知图标 → 一级导航（新对话⌘N、Pull Request、定时任务、插件、安全）→ 「项目」分组（项目 → 子会话缩进）→ 「最近」分组 → 底部用户卡（头像 + 名 + 帮助 ?）。
- **页面即主区**：定时任务/安全/设置都是**主区整页**（非模态）：大标题 + 副标题 + 右上角**黑色胶囊主操作**（"创建"/"＋ 扫描"）+ 搜索框 + 过滤胶囊 Tab + 列表/建议区。
- **主从结构**：安全页 = 左列表 + 右详情占位（"选择一项扫描以查看"）。
- 右侧面板窄条（约 280px）：工具项 + 快捷键提示（⌘T / ⌃`）。

### 1.2 配色
- 背景近白（主区纯白），**侧栏带极淡蓝灰色调**（约 oklch 0.97 0.005 250）——这是与主区唯一的色相区分。
- 边框极浅灰、无阴影（菜单/弹层用轻阴影）。
- **主操作 = 黑色胶囊按钮**（白字、rounded-full）；与我们现有 `--primary oklch(0.205 0 0)` 天然吻合。
- **功能蓝**：Switch 开态、选中态、链接、发送钮（淡长春花蓝）；**警示橙**：风险权限态（"完全访问"）；**紫色 pill**：升级 CTA。
- 语义色只出现在功能位（开关/权限/CTA），正文与容器保持灰阶——与我们 v1 的色纪律一致，只是多了**一个功能蓝**。

### 1.3 字体
- 系统无衬线（我们对应 Geist Variable）；页面大标题 ~24px/500-600；副标题 13px 灰；卡片行标题 13-14px/500 + 描述 12-13px 灰；菜单项 13px。**两级字重（400/500）+ 三级灰度**即可完成全部层级。

### 1.4 组件样式
- **超大圆角**：卡片/弹层 16–20px；输入框 20px+；按钮胶囊全圆角。
- 菜单行 = 图标 + 标题 +（可选灰描述）+ 右侧 kbd 快捷键/✓/chevron；分组带小字标签（"添加"/"插件"）。
- Switch 蓝色开态；分段控件（底部|右侧）；过滤 Tab 为浅灰底胶囊；搜索框浅灰底圆角。
- 空态：居中细线图标 + 一句标题 + 灰描述 + 黑胶囊 CTA。
- 横幅卡（用量提醒）：圆角 16、图标 + 粗标题 + 灰描述 + 右侧黑胶囊操作。

### 1.5 交互模式
- **芯片触发 + 锚定弹层**：输入区"完全访问"芯片 → 权限三态菜单（请求批准/帮我批准/完全访问，选中✓+橙色）；"自定义 中" → 强度滑杆弹层（离散档位）；"+" → 附件/插件分组菜单。
- 账户菜单：头像触发，顶部身份卡 + 分组操作行 + 快捷键标注。
- 设置页内搜索、返回应用链接。
- 全部 hover 浅灰行高亮；选中导航项浅灰底胶囊。

## 2. 落到本项目的设计令牌修订

在 `styles.css` 现状基础上**增量调整**（不动 oklch 灰阶骨架）：

| 令牌 | 现状 | v2 修订 |
|---|---|---|
| `--sidebar` | oklch(0.985 0 0) 纯白 | **oklch(0.972 0.004 250)** 淡蓝灰（dark: oklch(0.21 0.01 260)） |
| `--primary` | oklch(0.205 0 0) | 不变；**按钮默认改胶囊形**（`rounded-full`） |
| 功能蓝 | 无 | 新增 `--functional: oklch(0.55 0.16 255)`：Switch 开态/选中/链接/发送钮；发送钮用浅化级 `--functional-soft: oklch(0.75 0.10 255)` |
| 警示橙 | 无 | 新增 `--risk: oklch(0.60 0.15 55)`：高风险权限态/不可逆操作的文字与图标（按钮本体仍 destructive 红） |
| 升级紫 | 无 | 新增 `--upsell: oklch(0.62 0.19 300)` 仅 license/升级 CTA pill |
| `--radius` | 0.625rem (10px) | 不变；但**卡片/弹层用 radius-2xl(16px)**，输入框 radius-3xl(18px)，按钮 rounded-full |
| 字阶 | 未规范 | 页面标题 24/500 · 区块标题 15/500 · 行标题 13/500 · 正文 13/400 · 描述 12/400 muted |
| kbd | 无组件 | 新增：`text-11 muted bg-muted rounded px-1.5 py-0.5`，菜单右对齐 |

**需新增的 shadcn 组件**（现有 29 个之外）：`switch`、`slider`（强度档）、`popover`、`command`（⌘K）、`kbd`、`avatar`（用户/会话标识）、`toggle-group`（分段控件）。安装走 `npx shadcn add <name> -y`，改动标 `// @shadcn-modified`。

## 3. 布局结构修订

在 v1 四区骨架上修订三处：

1. **侧栏导航模型改为参考式**（替换 v1 的四组入口）：
   - 顶部：应用名 + 搜索（⌘K）+ 通知铃（审批/任务完成聚合）。
   - 一级导航：**新对话 / Agents / 定时任务 / 插件 / 安全**（安全 = 现有 security report 的页面化；五项均进主区整页）。
   - 「项目」分组：当前工作区 → 子会话缩进列表（即现有会话列表迁入，保留重命名/删除 hover）。
   - 「最近」分组：跨项目最近会话（无则显"无聊天"占位）。
   - 底部：用户卡（头像 + 名称 + ?）→ 触发**账户菜单**（见 §5.6）。
2. **页面分工重排**：定时任务/插件/安全从右面板**提升为主区整页**（大标题+黑胶囊主操作+搜索+过滤Tab）；右面板收窄为**会话上下文工具**：审批聚合、token 用量、diff/合并塔、记忆、旁聊、agents 运行态（6 个，schedule/plugins 页保留面板入口作快捷视图）。
3. **标题栏**：hiddenInset 红绿灯内嵌；左侧侧栏开关+前进/后退；右侧右板开关；中部不放 CTA（升级提示归入横幅，不污染标题栏）。

## 4. 核心页面修订（组件构成 + 交互）

### 4.1 会话工作台（默认页）
- **空态**（参考"我们要构建什么？"）：居中细线图标 + 20px/500 标题一句 + 下方输入框；不再用按钮式快捷动作，改输入框下方三个建议芯片。
- **输入区**（全面照参考重构，圆角 20px 卡片）：
  - 上行：项目选择条（浅灰底，"选择项目"）。
  - 输入框：「随心输入」占位。
  - 底行：`+`（附件菜单：文件和文件夹 / 目标 / 计划模式 / 插件分组，行=图标+标题+灰描述）｜**权限芯片**（当前模式名+图标 → 三态菜单：**请求批准 / 帮我批准 / 完全访问**，行=图标+标题+描述+选中✓，完全访问用 `--risk` 橙）——直接映射现有审批体系（批准一次/本会话放行/永久放行收敛为这三档，卡片内四钮不变）｜右侧：**模型/强度芯片**（"自定义 中 ⌄" → 离散滑杆弹层，档位 = M5b 路由档位表 low/mid/high + 自定义）｜发送钮（`--functional-soft` 圆形 ↑，运行中变停止 ■）。
- **横幅**（license/错误/沙箱降级）：参考用量横幅样式——图标+粗标题+灰描述+右侧黑胶囊操作，置输入区上方（现位置在消息流顶部，迁下来贴近操作区）。
- 消息流与 10 类卡片：骨架不变；卡片圆角升 16px；审批卡主钮改黑胶囊。

### 4.2 定时任务页（主区整页，照参考）
标题「定时任务」+ 副标题「让 Agent 按计划运行、提醒或监测」+ 右上**黑胶囊「创建」**；搜索框「搜索已安排任务」；过滤 Tab（全部/已开启/已暂停/已完成，胶囊选中浅灰底）；任务行 = 时钟图标+名称+「每天 10:00」人性化计划+启停 Switch；下方**「建议」区**（参考每日简报/每周回顾样式：彩色细线图标+标题+时间+一句描述）——预置三模板（每日构建检查/每周门禁报告/依赖监控）。行点击进入主从详情（右半：运行历史+编辑表单）。

### 4.3 安全页（主区整页，主从）
顶部过滤 Tab（扫描/发现项/报告）+ 右上黑胶囊「＋ 扫描」；空态 = 盾图标+「暂无安全扫描」+描述+黑胶囊「开始扫描」；列表+右详情（"选择一项扫描以查看"占位）。数据源 = 现有 security-check/report 管线。

### 4.4 插件页（主区整页）
信任插件卡列表（图标+名+描述+信任 Switch+MCP 状态徽标）；右上「安装」黑胶囊；风险插件用 `--risk` 橙标出（对应 loose skill 信任门）。

### 4.5 Agents 页（主区整页）
worker 卡片列 + 依赖链简图；右上「新任务」黑胶囊；点击 worker → 右侧滑出事件流详情（Sheet）。合并控制塔固定底条（待合并 worktree + 合并/丢弃，丢弃为 destructive+确认）。

### 4.6 设置页（**模态 → 全页**，照参考）
左侧设置内导航（返回应用链接 + 搜索设置 + 分组：个人[常规/外观/键盘快捷键/使用情况和计费]、集成[插件/MCP]、编码[权限/Git/环境]）；右侧内容 = 大标题 + 分组卡片（行 = 标题+描述+右侧控件：Switch 蓝/Select/分段控件/「更改」钮）。现有七组设置原样迁入此骨架。UI 组新增界面缩放（100/125/150%）。

### 4.7 账户菜单（侧栏用户卡触发的 Popover）
顶部身份卡（头像+名+方案徽标）→ 分隔线 → 行：用量（chevron 进 token 面板）/ 主题（⌥⇧T）/ 升级（`--upsell` 紫 pill + globe 图标）/ 设置（⌘,）/ 关于。全部行带右侧 kbd 或 chevron。

## 5. 响应式与自适应（沿用 v1，补充两条）

- 断点与 min 窗口 960×600 不变；**主从页**在 <1200px 时详情改 Sheet 覆盖（复用右板 Sheet 化机制）。
- 整页页面内容列 max-w-3xl 居中；设置页双栏（导航 220px + 内容弹性，min 560px），<1100px 设置导航收为顶部下拉。

## 6. 与 v1 的差异清单

| 项 | v1 | v2 |
|---|---|---|
| 定时/插件/安全 | 右面板 | **主区整页**（黑胶囊主操作 + 搜索 + 过滤 Tab） |
| 设置 | 模态 Dialog 分 Tab | **全页 + 内导航 + 搜索** |
| 权限入口 | 仅设置组 + 审批卡 | **输入区权限芯片三态菜单**（+ 审批卡不变） |
| 模型档位 | 设置组 | **输入区强度芯片 + 滑杆**（接 M5b 档位表） |
| 侧栏 | 会话+运行状态+设置钮 | 一级导航+项目+最近+用户卡；运行状态迁状态栏 |
| 按钮形态 | 默认圆角 | **主操作黑胶囊** |
| 色板 | 纯灰阶 | 灰阶 + 功能蓝/警示橙/升级紫三枚功能色 |
| 空态 | empty 组件一句 | 细线图标+标题+描述+黑胶囊 CTA |
| 新增组件 | — | switch/slider/popover/command/kbd/avatar/toggle-group |

## 7. 实施顺序（与 v1/性能报告节奏对齐）

P0：设计令牌修订（sidebar 蓝灰、功能蓝/橙/紫、圆角档）+ 新增 7 组件 + 黑胶囊主钮规范 → P1：侧栏导航重构 + 输入区重构（权限芯片/强度滑杆/附件菜单）+ 横幅迁移 → P2：定时/插件/安全整页化 + 设置全页化 → P3：Agents 页 + ⌘K + 账户菜单完善。

**验证纪律不变**：renderer 域改动回归 `pnpm panels-check` + `pnpm gates`；960/1280/1920 三档截图断言；样式令牌改动需 dark/light 双主题目检（对比度 AA）。
