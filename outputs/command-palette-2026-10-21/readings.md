## 面板几何

- 620 × 640 @ (410, 125.6)；顶部仍留 80px 视口边距；列表内滚。
- 33 个条目全部带 `.cp-ico`（12 操作 + 8 会话 + 3 会话动作 + 10 设置）。
- 分组：操作 / 会话 / 设置（本样本工作区没有注册项目，项目组按数据面缺席，不摆空组）。
- 空查询选中项 = 第一条；↑↓ / ⏎ / esc 页脚提示在位。

## 行为

- **最近**：执行「切换主题」后重开面板，`最近` 组在顶部且恰一条「切换主题」；
  localStorage 只存 action id，上限 4、去重。
- **上下文**：主页打开面板不含「复制整段对话 / 压缩当前会话历史 / 查看当前会话日志 /
  导出 / 查找」；进入会话后五条在场（不再给必然报错的入口）。
- **搜索同义词**：输入「密钥」只命中「设置 → 模型与 Provider」（`SECTION_KEYWORDS` 并入 value）；
  会话条目可按 id、项目条目可按路径搜（源码判据）。
- **主题**：浅色面板 `rgb(252,252,251)`；暗色 `rgb(30,30,29)`（elevated，不再比应用底更暗）；
  图标/键位中性灰，选中行图标抬到主文字色。
- 控制台 0 异常。
