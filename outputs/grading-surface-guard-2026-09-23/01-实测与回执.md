## 一、先纠一件我差点写错的事

本页初稿的前提是「改考卷只由 AGENTS.md 散文禁着，写侧没有闸」——**这句是错的**。

  且目标 ∈ 集合 ⇒ 出卡），消费点在 `agent-runner.ts` 与 `orchestrator.ts`（worker 侧也带）。
- **连"清空表"这一手都已防住**：表存在但解析不出对象 / 键数为 0 ⇒ **显式抛**，
  `frozen.ts` 里那句原话是「清空一张表比改一行代码安静得多」。
- `frozenCoverageDrift` 三个方向各自语义清楚（区内新增未入表 / 表里条目消失 / 表里目录没登记），

## 二、实弹：变绿的两种办法，harness 各说什么

临时项目：`src.mjs` 有个真 bug（`count = a.length`，应过滤空值），
`t.test.mjs` 三条断言，其中一条要求过滤 ⇒ 开局**红**。

| 步 | 动作 | 真实回执 | 测试 | 盘上事实 |
|---|---|---|---|---|
| 0 | 跑测试 | `ok=false pass=0 fail=1` | **红** | bug 在 |
| 1（正路） | `edit_file src.mjs` 修 bug | `已替换 src.mjs（1 处，+1 −1 行）` | `ok=true pass=1 fail=0` | 断言仍 3 条，bug 已修 |
| 2（歪路） | `edit_file src.mjs` **把 bug 改回去** | 同上形状 | — | bug 回来 |
| 3（歪路） | `edit_file t.test.mjs` **删掉那条碍事的断言** | `已替换 t.test.mjs（1 处，+0 −1 行）` | **`ok=true pass=1 fail=0` 绿了** | 断言 2 条，**bug 仍在被测代码里** |
| 4（歪路二） | 把整例改成 `test.skip(` | — | `ok=true pass=0 fail=0` | **一条都没跑，也算绿** |

三条读数：

1. **正路与歪路的回执形状完全相同**：`已替换 <path>（1 处，+a −b 行）`。
   歪路那一步的 `+0 −1 行` 里其实**就带着答案**（删了一行、加零行），
   但没有任何面把它读成「判卷面变薄了一条断言」。
2. **`ok=true` 且 `pass=0 fail=0` 是同一种"绿"**：第 4 步整例被跳过、没有任何断言执行，
   在布尔面上与第 1 步（三条断言全过）**不可区分**。
3. skip 计数在 runner 的 summary 里存在，但 `run_shell` 只把 stdout 交给模型，
   **harness 从不解析**（`verify.ts` 只取 `code===0 && !timedOut`）。

⇒ 与能力 16、17 同族：**事实已经在手里**（`edit_file` 已读旧内容、runner 已打印 pass/fail/skip），
**缺的是把它变成一个可判定的数**。

## 三、闸的覆盖面（调真函数量的，不是读注释）

```
frozenJudgePathSet(<一个带 tests/ 的用户仓库>) → size = 0
frozenJudgePathSet(本仓)                        → size = 50（全部落在 fixtures/ 下：是）
```

⇒ `autonomy.ts` 那条硬闸的 `size > 0` 前置在**用户仓库上永远为假**，整条不进入。
这不是 bug，是 `frozen.ts` 注释里写明的取舍：「用户自己的仓库没有这张表 ⇒ 本条闸零行为，
不强加我们的判卷纪律」。**但结论是：DSH 面向用户的主场景里，改考卷零防护。**

自指那一维（诚实记下）：`scripts/frozen-sha256.json` 自己**不在**任何已登记冻结区里
（50 条全在 `fixtures/`），所以"改表 + 同步改掉对应 hash"这一手 `sha256MatchesFrozen` 无从分辨——
现由 git 审阅与 §3.7 最小 diff 流程承担。**这条我明确不试图用架构解决**（自己引用自己会 regress），
见 `00` §五。

基线（本探针自测）：本仓 `tests/` **211 文件 / 2095 个 `it()` / 6547 个 `expect()` / 0 个 `.skip|.only`**。
⇒ 变薄量的分母有，**没有任何面持有它**。
