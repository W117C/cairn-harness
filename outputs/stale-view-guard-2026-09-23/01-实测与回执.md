## 一、实弹结果：今天写路径上的「静默删除」是什么样子

这一段是本页的全部理由。前提交代清楚：

- 模型 `read_file` 看到 V1（3 行）；
- **第三方**往文件尾加了一行 `export const audit = true;`（盘上变 V2，5 行）——
  等价于「格式化器跑过 / 并发 worker 写过 / 用户手改过」三类现实事件之一；
- 模型此刻按它脑中的 V1 落笔。

真实工具（`src/tools/write_file.ts` / `src/tools/edit_file.ts`，含在飞的 D7 快照改动）的实际回执：

| 动作 | 工具回执（逐字） | 盘上后果 | 回执里有没有第三方那行 |
|---|---|---|---|
| 模型整份 `write_file`（基于旧视图） | `已写入 src/widget.ts（61 字节，+1 −4 行）` | **`audit` 那行被删** | **没提** |
| 模型 `edit_file` 精确删掉 `audit` 那行 | `已替换 src/widget.ts（1 处，+0 −1 行）` | 删了 | 没提（此条模型本来就想删，不算缺陷） |
| 模型从未读过该文件就整份 `write_file` | `已写入 src/widget.ts（20 字节，+1 −6 行）` | 5 行原件全没 | **没说「这 6 行你没读过」** |

三条读数里最有价值的是**第一和第三条**：

1. **数字是对的，归属是空的。** `−4 行` / `−6 行` 已经在回执里了——`write_file` 为了算这个数
   已经把旧内容整份读进手（`src/tools/write_file.ts` 里 `oldText` 那一段），算完就丢。
   ⇒ 缺的不是信息，是**「这 −N 行里有几行是模型从未见过的」这一句话**。所以这条能力的成本
   不是「要多读一次盘」，是「把已经读到手里的东西说清楚」。
2. **绿色回执 + 静默删除 = 最坏组合。** 没有任何一个字段、一行文案让模型（或人）知道
   刚刚删掉的不是自己的东西。D7 在飞的 `snapshotBeforeOverwrite` 把原件抄进了
   `.agent/snapshots/`，那是**恢复**；本页要的是**检测**——两者不重叠，也不互相替代。

## 二、真语料读数（26 个会话文件 / 209 次工具调用 / 73 次写侧调用）

| # | 读数 | 值 | 判读 |
|---|---|---|---|
| M1 | 写某路径前，本会话从未对该路径 `read_file` 成功过 | **8/73 = 11.0%** | 缺口真实存在，但不是主战场 |
| M1b | 其中属于整份 `write_file`（最高危那一类） | **0** | **unmeasurable**：真语料里模型根本不整份重写（见 §四） |
| M2 | `read_file` 结果的覆盖面 | 整份 130 / 窗口 0 / 截断 **0** | 覆盖面分档在本地语料**没有观测者**；设计必须被它「不因缺观测而错」，而不是「已证明需要它」 |
| M3 | `edit_file` 失败（0 匹配 / 多处匹配） | **0 次失败** | 「0 匹配→重读→再改」那笔返工成本在本语料**量不到**，不许当已证收益 |
| M4 | 升级签名（edit 失败 → 同路径整份重写） | **0** | 同上，unmeasurable |
| **M5** | **同路径二次覆盖，且中间没有重读** | **14/73 = 19.2%** | **本能力真正的本地抓手**：模型改完自己不看盘就再改，第二次「看不见账」直接落笔 |
| M6 | `read → write` 之间夹的工具调用数 | n=65，中位 **3**，最大 **6** | fixture 跑得很短 ⇒ 第三方改动的窗口小；真长会话上这个数只会更大，本地无法给出（标 unmeasurable） |
| M7 | 整份重写字节 vs 精确编辑字节 | 0 / 6024 | 与 M1b 同因 |

**M5 为什么是关键读数**：14 次「自己刚改过、没重读、又改一遍」。模型第一次改完，
它掌握的磁盘状态是**从回执推出来的**（`+a −b 行`，没有内容），不是**看来的**。
⇒ 账本必须在**写成功之后也记一笔**（把「我刚说过的新状态」记为基线），
否则每次自改之后都会退化成「没见过」。这一条是纯本地读数驱动出来的设计决定，不是先想好的。

## 四、把「未证」和「已证」分开（G7 口径）

**已证（可复跑，读数在上）**
- 写路径上不存在任何「文件自模型上次所见已变」的检测（`src/tools/**` 全扫，见 `00` §二表）。
- 整份重写会静默删除第三方行，且回执为绿（§一 第 1、3 行）。
- 同路径无重读二次覆盖的基础率 14/73（§二 M5）。

**未证 / 本地无观测者（不得写成收益）**
- 「0 匹配返工」的实际代价（M3=0）。
- 「模型整份重写」在真流量里的占比（M1b=0，M7=0）——本语料全是 mock 剧本 + fixture 短跑。
- 截断/窗口读带来的「见过 ≠ 见过整份」误报面（M2 截断=0）。
- 并发 agent 真的会同时改一个文件（本仓 worker 走 worktree + `lease-conflicts`，
  与「模型 vs 盘」不是一条链）。
- 加了这个闸之后**返工率是否下降**——必须等它在真会话上跑出一个「拦下次数 / 误报次数」对。

⇒ 落地顺序相应地定在 `00` §五：**先只报不拦（detection 默认开、enforcement 默认关）**，
让上面这四条未证各自长出自己的观测者，再谈默认拦。
