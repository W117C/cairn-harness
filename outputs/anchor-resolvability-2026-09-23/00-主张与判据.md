# 能力 30：锚点可解性（指针还能不能走到地址）

一句话：**文档是指针的长寿面、代码是短寿面**，而本仓那条"别用行号当锚点"的规矩，
正则里只覆盖了指向 `.md` 的指针——最常见的 `verify.ts:43` 形态，写在 `.md` 里和写在 `.ts` 里**两处都不管**。
今天实测：散文页 2129 条行号锚点里 **173 条按今天的仓库根本找不到那个文件**，且这批死锚的多数
由本程序自己这几天写的页制造。

## 一、空位核对（这次连错两次，把真身留下）

| 看着像"已有人在守"的面 | 实测管辖 | 漏掉的部分 |
| --- | --- | --- |
| D-3 `checkLineCitations`（`scripts/docs-check.ts`，带 LEGACY 豁免棘轮） | 正则 `LINE_CITATION`（同文件）= `/[\w./#-]+\.(?:md\|markdown):[0-9]+/`，扫描面 `listSourceFiles(ROOT)` = `src/scripts/tests` 的**代码文件**，共 440 个、全是代码扩展名 | **目标扩展名只含 .md**，且**不扫 .md 内容**。真函数三对照：`.md` 正文 3 条 `x.ts:NNN` → 报 **0**；`.ts` 注释 1 条 `src/agent/loop.ts:1` → 报 **0**；`.ts` 注释 1 条 `docs/plan.md:1` → 报 **1** |

⇒ **结论不是"没人想到"，是"想到了、写成了管错对象的门"**。这与能力 28/29 同一类：
不变量在文档里活着，在判定层里缺席。

## 二、为什么这是 agent 通病（不只本仓）

模型写文档时拿的是**当下快照**（甚至凭上下文记忆），写下的行号在下一次读取时就可能已经属于另一个函数；
读取者（人或模型）按锚点跳过去，**读到邻近但不同的代码**比读不到更坏——它会生成一个自信的错结论。
本仓并发多会话写同一批文件（AGENTS.md 已记"同一小时内 2418→2421"），这条通病被放大。
可解性不是格式问题，是**指针必须有可判定的地址**：要么落到文件/符号（永可解），要么带一段可对照的锚文本。

## 三、判据总则

分三类，且不混报一个数：**硬事实**（今天按指针找不到东西）、**弱信号**（找得到但那行不像被指的东西）、
**歧义**（找得到，但仓里有多本同名文件，读者自己猜）。判卷只用硬事实。

## 五、已证 / 未证（含两次作废记录）

**已证**：① 三对照 0/0/1；② 分布 `path-ok 343 / basename-unique 3 / basename-ambiguous 1042 / dead-file 173 / out-of-range 0 / blank-ish 568`，
其中 `outputs/` 分别 255 / 3 / 1016 / 139 / 0 / 522。两次跑 `diff -q` 逐字一致。

**作废读数（当场记，不回改原文）**：
1. **第一版 ② 得出 78.1% file-missing** —— 把裸名锚点按 ROOT 相对路径解，分母整个错。
   加 basename 回退后真值 8.1%。教训同 25 页 `read(rel)` 双重 join：**分母错了比结论错了更难发现**。
2. **第一版 ① 读成"规则本身能判、只是没喂散文"** —— 也是错的。真因是**目标扩展名白名单**（`.md`/`.markdown`），
   与文件集无关；这条也是本页头号主张，写错就等于把施工面指错地方。

**未证 / 不可用**：
- **③ 整问今天不可作判卷**：歧义锚点只按第一个候选解析 ⇒ 漂移数是上界噪声（实测 2017/2183 明显失真）。
  留作歧义消解后的候选判据（C6）。
- **dead-file 里混着两类不该算缺陷的**：(a) 指向**宿主外部文件**（`node-safe-delete-shim.cjs:195`）；
  (b) **设计指针**——提案里指向"打算新建但还没建"的文件（`docs/solpi-port-proposal.md` 里 `SECURITY.md:3`、
  `observation.ts:13`、`receipt.ts:50` 等一整批）。⇒ 真门的红名单必须先分这两类，
  否则第一版门会因提案页恒红而被关掉（本仓 `map-check`/`panels-check` 的假红教训同源）。
- 173 条死锚里"曾存在后被改名/删除"的占多少未测（需拿 HEAD 与工作树各解一遍对照）。
- `out-of-range = 0`：说明漂的主要是"**是哪一本**"而不是"第几行"——这一条反过来支持"强制全路径 + 符号名"的修法。

## 六、最小施工（一只门 + 一条书写规矩）

1. **门**：把 ② 的解析器搬进 `scripts/`（或并入 `docs-check` 作新条），扫 `AGENTS.md`/`PROGRESS.md`/`docs/**`/`outputs/**`；
   硬事实态（`dead-file` 且非外部/设计指针、`out-of-range`）\> 0 即红，**水位进 `LEGACY_WAIVERS` 只降不升**；
   弱信号与歧义两态只进"待核清单"不参与退出码（同 `recheck-blockers.mts` 的 `flakyClaim()` 分面思路）。
2. **书写规矩**：指向代码的锚点必须**文件 + 符号名**（`src/agent/stuck.ts` 的 `stuckObservationOf`），
   符号在文件内唯一时可省行号。这条把 AGENTS.md 已有的散文规矩变成可判定形式，
   并给"确需行号"留行级豁免（照 `docs-check:allow <理由>` 现成的逃生舱写法，别新造格式）。
3. **自纠但不伪历史**：本程序**新页**一律用文件+符号；已写页交给门的水位处理，
   **不批量改写历史文本**（append-only 是这批准入的硬纪律，`checkAppendOnlyCorrections` 已在校）。
