# 档案层（archive）

这里放**不再现行的结论**与**历史图**：它们仍然是审计链的一部分（要查"当时为什么那么判"就到这儿），
但已经不该出现在现行层（`AGENTS.md` / `STATE.md` / `docs/README.md` / `docs/CODE-WIKI.md`）。

## 什么该进这里

- 一份裁决**被后来推翻**之后，被推翻的那一份原文（连同它的理由与页号）留在 `PROGRESS.md` 的对应页；
  搬进这里的是**结论本身**——现行层只需要知道现在的结论，不需要知道它被推翻了三次。
- 证据图（截图、录屏、导出物）：`docs/` 下不留二进制（`docs-check` D-7 守这条），
  当前证据落 `outputs/<主题>-日期/`，不再当证据用的历史图落这里。
- 某一轮的**实录**（长日志、逐条读数）：台账页只留结论与指针，原始输出在这里。

## 什么**不**该进这里

- **台账层**（`PROGRESS.md`）：它是审计链的主干，**不搬进来**。门有多张面直接拿它当事实源
  （D-5/D-9/D-10/D-11/D-12/D-13），搬走会让那些面停止覆盖历史那半——
  "读不到"被读成"没问题"，是本仓最忌的假绿形状。
- **现行层**：这里不是"暂存区"。现态页瘦法是**把结论迁进 `archive/`**，不是把现态页搬过来。

## 引用纪律

引用档案层的东西要带**页号或路径**（`PROGRESS.md` 的页号、`outputs/` 的目录名），
别写"见档案"这种指不出来的引用（`docs-check` D-3 要求指针可追）。
