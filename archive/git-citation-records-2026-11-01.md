# 台账历史提交对象

`PROGRESS.md` 引用的 27 个原始 commit 对象仅残留在开发机对象库中。其所属旧开发链的
祖先 `767126682007a2c37bde6012f082e878c9890ec7` 及部分树/文件对象已损坏，远端也没有该祖先，
因此不能作为正常分支推送。损坏审计原件位于开发机的 `git-quarantine-20261026/`。

同名 `.pack` 只保存这些原始 commit 对象，未重写作者、消息、父提交或 tree。`.json` 列出
完整 SHA 和包的 SHA-256。CI 用 `git unpack-objects` 恢复原对象供 D-5 检查引用身份；回归测试
在全新空 Git 库中恢复并重算各对象 SHA，同时验证损坏包会失败。

这份归档证明提交记录的身份，不证明缺失祖先已恢复、历史代码树完整或历史测试通过。
不把这些对象挂到分支或标签，以免形成无法遍历的引用。
