# 路线与非目标

## 现在

- **0.2.x 开发者预览**：CLI 可跑；macOS 桌面壳可构建、可打包（ad-hoc 签名、未公证）。
- 核心能力：项目/会话、工具调用、权限四档、沙箱、记忆、插件、自动化、诊断包。
- 质量：核心与桌面行为测试全绿；产品契约门在每次 PR 运行。

## 下一步（按优先级）

1. **首次启动**：把「选模型 → 连 provider → 选项目 → 第一个任务」做成向导，不再要求用户先读文档。
2. **可分发安装包**：0.2.x 预览 DMG（SHA-256 + 首次打开说明）；后续补 Developer ID 签名与公证。
3. **普通用户任务模板**：做展示页 / 做小工具 / 改已有项目——按 ADR 0004 的首批任务类型提供可点击的起点。
4. **平台与语言**：评估 Windows 与英文 UI；在此之前，README 首屏明确写「macOS / 中文 / 开发者预览」。

## 非目标（当前版本）

- 账号体系、团队协作、云端托管、支付；
- 数据库/后端服务托管；
- 跨软件桌面操作；
- 对未验证模型的「能力排名」或营销式评分。

路线会随真实用户反馈调整；本页只写方向，不写内部排期。
