# 队列保存与派发顺序

持续优化目标下的本批修复，目标保持 active。现有队首在 queueSet 应答前即出队并执行；写入失败只显示错误，无法阻止执行或恢复队首。

方案：提取 renderer 队列持久化职责，按工作区/会话串行写入和出队；出队成功落盘后才派发，失败在本窗口恢复队首及后续编辑。自动续发遇到未解决的保存失败停表，显式恢复才重试。整条 drain 防重入，异步取队列期间的新消息仍进入同一目标队列。队列行按渲染 id 寻址，保存中禁止修改并显示状态。

host 回传用户轮是否已接收；只有明确未接收的队列请求恢复入队，已接收但执行失败的请求不自动重发。协议升版，复用既有版本闸。
