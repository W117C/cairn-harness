# 任务：重做 Cairn 桌面端主界面（侧栏 + 空屏 + 输入框 + 对话区）

> 本文件为业主 brief 原文副本（2026-10-16，会话消息，权威口径以 transcript 为准）。
> 实施计划见同目录 `2026-10-16-desktop-main-ui-rework.md`。

沿用之前设置页改造中建立的 design tokens 和组件库（SettingsRow 等不用动）。本任务只覆盖：侧栏、空屏、输入框（Composer）、对话区与右侧检查器。现有布局和交互思路整体作废，按下面方案重做。

## 第 0 步：先读后改
读 apps/desktop 中侧栏、空屏、Composer、附件/模型/权限弹窗、会话列表的实现，以及 IPC 层现有的文件选择、工作区、会话相关接口。写一份计划，然后分阶段执行。

## 核心原则
1. 用户永远不需要输入绝对路径。路径校验仍由 main 进程完成，但 UI 层不暴露任何内部实现细节。
2. 界面上不出现开发者术语：RunRequest、attachments、main、run 前校验等一律不显示。必要的解释放进 "?" 提示，文案用人话。
3. 少即是多：同一屏上的可见控件尽量少，次要操作收进 ⌘K 命令面板或右键菜单。
4. 每个图标按钮必须有 tooltip；高频操作必须有快捷键，并在 tooltip 里显示。

## 二、侧栏重做
顶部：
- 「＋ 新任务」主按钮（⌘N），其右侧放搜索（⌘K 打开命令面板：搜会话、切项目、执行命令）。
- 删除现在那排 4 个无文字图标和行内表单。

项目区（取代"工作区"）：
- 按项目分组，项目可折叠，显示文件夹名（完整路径放 tooltip，不直接展示），有未完成任务的项目显示小圆点。
- 项目列表底部有「添加项目」入口，点击展开菜单：
  1. 打开文件夹…（系统选择器，⌘O）
  2. 新建项目…（打开弹窗，见第四节）
  3. 从 Git 仓库克隆…（输入 URL，选择保存位置）
  4. 最近打开（列出最近 8 个项目，一键添加）
- 支持把文件夹直接拖进窗口（侧栏或空屏任意位置）即添加为项目，并给出 Toast："已添加 xxx"。
- 项目右键菜单：在 Finder 中显示、重命名显示名、移除（不删除文件，说明清楚）、项目设置。
- "其他"改名为「临时对话」，用于没有绑定项目的会话。

会话列表：
- 标题自动生成：首条消息发出后异步生成 ≤20 字的标题（用当前模型或截取首句，失败则回退为截取首句）；用户可双击重命名。
- 每项一行：状态图标（运行中转圈 / 等待审批黄点 / 完成对勾 / 失败红点）+ 标题 + 右侧相对时间（刚刚/3分钟前/昨天）。
- 超长标题用省略号，不用渐隐；hover 显示完整标题。
- 按时间分组（今天/昨天/过去7天/更早），支持置顶、重命名、归档、删除（删除需确认）。
- 空列表文案："还没有任务，按 ⌘N 开始"。

底部：
- 设置入口（齿轮，文字「设置」）和头像；当前 provider 状态点（绿=可用，红=不可用，点击进入设置）。

## 三、空屏重做（输入框居中，发送后下沉）
- 空屏时输入框位于视觉中心偏上，紧贴问候语下方，不再钉在底部；发送第一条消息后用 200ms 动画下沉到底部，对话区展开。
- 问候语："今天想做点什么？"（可按时段变化），副标题只在首次启动显示。
- 输入框上方一行显示当前项目 chip：「📁 cairn-harness · main」，点击弹出项目切换（带搜索 + 最近项目 + 「添加项目…」）；没有项目时显示「选择项目」，并提示"也可以直接拖入文件夹"。
- 输入框下方是"快速开始"建议，按项目动态生成，而不是写死：
  - 读取项目信息：package.json scripts、git status、最近失败的测试、README 是否存在、最近一次会话。
  - 例如："继续上次：修复登录测试"、"有 3 个未提交的改动，帮我检查一下"、"运行测试并修复失败项"、"解释这个项目的结构"。
  - 取不到信息时回退到 3 条通用建议（不要出现任何具体文件名）。
  - 点击建议：填入输入框并聚焦，不自动发送。
- 删除 "⌘N 任何时候回到这个页面" 那行；改成输入框 placeholder："描述任务，/ 调用技能，@ 引用文件"。
- 顶部不放多余装饰，保留一个克制的品牌字标即可。

## 四、新建项目弹窗（取代侧栏内联表单）
- 居中 Dialog，不是侧栏里的行内表单。
- 步骤：先选模板（卡片网格：空项目 / 展示网页 / 脚本工具 / 文档笔记…，每张卡有图标和一句话说明，模板清单以现有为准），再填项目名（实时校验重名与非法字符），再选位置：默认 ~/Cairn Projects（首次使用时自动创建），旁边「更改…」打开系统选择器。显示"将创建在：xxx"预览。
- 创建后自动加入侧栏并聚焦输入框。

## 五、输入框（Composer）重做
结构：上方文本区（多行自适应，最多 8 行，之后内部滚动），下方一行控件。

控件行（从左到右）：
- 「＋」：菜单项为「上传文件…」「添加文件夹…」「粘贴截图（⌘V）」「引用最近文件 ▸」。没有路径输入框，没有解释段落。
- 权限 chip：显示当前档位名 + 颜色圆点（只读=灰绿，默认=蓝灰，引导=黄，自动=红）；点击弹出 4 档选择，每档一句话说明。
- 模型 chip：显示「模型名」，思考强度合并在同一个弹窗里；弹窗内：模型列表（可搜索，显示上下文长度、是否支持思考/图片）、思考强度 Segmented（关/低/中/强，每档一句话说明，按模型能力禁用不支持项）。chip 上只显示"模型名 · 思考强度"，且每个会话记住自己的选择。
- 右侧：发送按钮（⏎，Shift+⏎ 换行）。生成中变为「停止」按钮（⌘.）。
- 检查并移除现在那个意义不明的 "—" 圆按钮和右上角的 "Tab" 角标：先确认它们的真实功能；有用则改成明确的图标 + tooltip，没用则删除。

引用与附件（完全不让用户碰绝对路径）：
- 输入 @ 弹出文件模糊搜索（范围：当前项目；显示相对路径，带文件图标，↑↓ 选择、⏎ 确认、Tab 补全），选中后在输入框内变成可删除的 chip。
- 支持拖拽文件/文件夹到输入框或窗口：项目内的文件直接转成 @ 引用；项目外的文件作为附件，并在 chip 上标注"项目外"，发送时仍走原有的外部引用审批。
- 支持 ⌘V 粘贴截图和文件。
- Electron 取本地路径请用 webUtils.getPathForFile（不要依赖已废弃的 file.path）；路径在 UI 里只作为 tooltip 展示。
- 附件 chip 显示：图标 + 文件名 + 大小，可点击预览，可删除。
- 输入 / 弹出技能和命令列表（带搜索和描述）。
- 项目外引用需要审批这件事，用 chip 上的小盾牌图标 + tooltip 说明，不再写长段文字。

## 六、对话区
- 内容列限宽 760px 居中；用户消息右对齐轻量气泡，agent 输出无气泡、左对齐。
- 工具调用卡片：默认折叠为一行（图标 + 动作摘要 + 耗时 + 状态），展开后看命令/参数/输出；写文件显示行内 diff。
- 审批卡片：醒目但克制，显示"要做什么、影响范围"，按钮：允许一次 / 本会话允许 / 拒绝；键盘 ⏎ / Esc。
- 生成中：流式光标 + 顶部细进度条；错误态：清晰原因 + 「重试」「查看日志」。
- 消息 hover 操作：复制、从此处分叉会话、回放到此步（对应事件日志的 fork/replay）。
- 长对话：浮动「回到底部」按钮；滚动位置记忆。

## 七、右侧检查器（默认收起）
三个 Tab：
- 改动：本次会话修改的文件列表（+/− 行数），点击看 diff；提供「撤销此文件改动」（仅对有备份/可回滚的情况显示）。
- 计划：agent 的任务清单/进度（若内核有该数据，否则隐藏此 Tab）。
- 时间线：基于 JSONL 事件日志的步骤时间线，可点击跳转到对话中的对应位置；这是 Cairn 的核心卖点，要做得清楚好看。
没有对应数据的 Tab 一律隐藏，不放占位假数据。

## 八、命令面板（⌘K）
可搜索：会话、项目、设置页、技能、常用操作（新任务、添加项目、切换主题、切换权限档）。键盘优先。

## 九、快捷键（统一在设置里展示，tooltip 里同步显示）
⌘N 新任务｜⌘O 打开文件夹｜⌘K 命令面板｜⌘⌥B 检查器｜⌘. 停止生成｜⌘⇧[ / ] 切换会话｜⌘, 设置。

## 约束与验收
- 不改内核事件格式和 CLI；需要新增 IPC（如最近项目、git 状态、标题生成、文件模糊搜索）时，写最小接口并在计划中列出。
- 没有数据支撑的功能不要造假数据；隐藏或标"即将推出"。
- 所有文案走 i18n，中文简短、不含开发者术语。
- 动效 120–200ms，尊重 prefers-reduced-motion；亮/暗两种主题都要检查。
- 分阶段提交并停下给截图：
  P1 侧栏 + 项目管理（打开文件夹/拖拽/新建/克隆/最近）+ 会话列表
  P2 空屏 + Composer（含 @ 引用、拖拽、粘贴、模型/权限弹窗）
  P3 对话区组件 + 右侧检查器 + ⌘K 命令面板
- 自查清单：全流程没有任何一处要求输入绝对路径；界面上搜不到 RunRequest / attachments / main 等字样；所有图标按钮都有 tooltip；空列表都有引导文案。
