# macOS 内测试用与稳定性修复

用户于 2026-11-01 授权按项目评估开始修复，并明确暂不做 Apple Developer ID 签名、公证。

目标：产出可交给受邀 macOS 用户的桌面包，修复已经发现的交付与验证阻断。沿用现有 Electron、权限、会话、打包及诊断能力，不新增依赖，不改全局 Gatekeeper 设置。

范围：

- 保留共享工作树已有改动，定点修复；不把其他批次整体提交。
- 共享子流判据继续只有一个实现。派生层允许使用经过纯度检查的核心纯模块，禁止宿主运行时、时钟与可变态回流。
- 恢复已有打包图标和仍被引用的字体；沿用本地 ad-hoc 封装，不申请证书。
- 安装说明只允许对用户已确认来源的 Cairn.app 移除 quarantine，不关闭系统保护。
- 打包凭据注明基线 commit、工作树是否含未提交修改；旧构建信息保持可读。
- 设置和终端冒烟修复过时的界面假设，原有行为断言保留，增加窄窗收起/重新展开覆盖。
- 构建、打包态及移出源码树的启动都实际验证。真实模型与另一台 Mac 的结果独立记录，缺少条件时不冒充通过。

验收：渲染分层、typecheck、docs、core/desktop 套件及相关真实 Electron 冒烟通过；新包能够离开源码目录启动。外部机器验收仍需外部样本。
