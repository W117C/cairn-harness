# bot 团队 与 玻璃壁纸：与参照物的逐项对表（「行业最高」到底指什么）

状态：参考材料／自评表（不是裁决，也不是验收记录）。日期：2026-11-16（Asia/Shanghai）。
证据基线：HEAD `fb39584f` ＋本批未提交改动；本表的读数来自本仓自己的判据（见每行「我们的证据」）。

## 0. 为什么写这一页

「做到行业最高」如果只当形容词，就没法验。这一页把两件事拆成**可以逐条对表的维度**，
每条写：参照物怎么做、我们怎么做、我们的证据在哪、以及**我们承认还不如它**的地方。
参照物两个：上游 `Fei2411/DS-Bot`（bot 团队，Apache-2.0，仅作参考材料）与
`elysia395/dsh-wallpaper-engine`（玻璃壁纸，DSH 插件）。

## 2. 玻璃壁纸

| 维度 | 参照物 | 我们 | 我们的证据 | 谁更强 |
|---|---|---|---|---|
| 媒体通道 | 插件挂同源 HTTP 路由 | 自定义协议 `cairn-wallpaper://`，白名单＝设置里那一个文件；Range/206/416 | 真机冒烟（200/206/404/416） | **我们**（白名单是机制，不是约定） |
| CSP 承重 | 未提 | 反证臂：摘掉 `img-src` 里的 scheme ⇒ 图**必须**加载不出来 | 冒烟「反证：摘掉 img-src…」 | **我们** |
| 文字可读性 | 网格法算地板（值得抄的机制） | 地板由**真实计算样式**现算，模型常量与真机真值差 ≤2/通道（漂移守卫） | 亮色 43%/4.630:1、暗色 61%/4.526:1、drift 0 | **我们**（它是手抄常量，我们是量出来的） |
| 首帧 | 未提 | 图片壁纸取 1×1 PNG 平均色当窗口底色（裸位图的通道序随平台变，所以走 PNG） | 冒烟「真 Electron 接受首帧底色」读回 `#7E457F` | **我们** |
| 生命周期 | 失焦/隐藏即停 | 失焦/隐藏/**系统休眠与锁屏**（真 `powerMonitor` → 真 IPC → 暂停/续播） | 冒烟 ⑨b、⑭ | 平（它还有遮挡判定；我们写明「不做」） |
| 默认与降级 | 默认开、插件载入即生效 | 默认关；媒体 404 ⇒ 撤层＋设置行点名「文件不可用」 | 冒烟 ⑩ | **我们**（失败可见） |
| 场景/工坊/频谱/吉祥物 | 有（Wallpaper Engine 生态） | 明确不做（装饰不承载信息） | spec §8 | **它**（生态与特效） |

**结论（壁纸）**：在我们选定的范围内（单文件本地图/视频＋玻璃面＋可读性地板＋省电），
每一格都有真机读数，且**判据本身**比参照物严（反证臂、漂移守卫、地板现算）。
没做的（场景引擎、工坊、频谱、特效）是**范围外**，不是欠账。

## 3. 这套判据本身算不算「行业最高」

一句可验的话：**每个「完成」背后都有一次能在本机重跑的真机读数**，而不是一句形容词。
本批的三条硬要求都落在闸里：类型 0 报错、桌面 405 文件/2617 条、核心 685 文件/8221 条、
壁纸冒烟 48/48、四份密封证据与当前 renderer 同代。做不到的地方（原生面板点选、
OS → powerMonitor 的一跳）在台账里逐条点名，不混进「已验」。
