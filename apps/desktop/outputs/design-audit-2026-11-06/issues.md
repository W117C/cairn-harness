## 严重度口径

- **P0**：明显错位、遮挡、暗色不可读或空假数据；应在集中修复先做。
- **P1**：跨面不一致、层级/密度不统一、重复入口或信息冗余。
- **P2**：打磨项，不影响任务完成但削弱精致度。

| 12 | P1 | `06-settings` 至 `22-settings-worktrees` | 16 个分区共用同一「标题 + 横线 + 纵向开关行」模板；部分页（Hooks、迁移导入、技能中心）内容极少，标题下出现大片空白，密度与高级/快捷键页差异过大。 | 按信息量给三档模板：单组设置、表格设置、空态设置；少内容页允许双列摘要卡或引导语，避免一条横线撑全宽。 |
| 13 | P2 | `07-settings-general` | 分区搜索把导航收窄到「通用」一项后，主内容仍是完整通用页；搜索结果与内容没有联动反馈，容易误以为搜索只过滤菜单。 | 搜索命中时给内容区一条轻量结果提示或自动滚动到命中分区的标题，保持诚实：它只搜分区名。 |

| 15 | P2 | `14-settings-usage` | 四个统计数字、单柱日消耗、输入/输出条与活动日历同时出现，数据稀疏时（1 条记录）图表仍占大块面积，视觉上把少量事实放大成趋势。 | 低样本时退化为统计行 + 说明，不画趋势图；达到阈值再展示图表，阈值与空态文案进 strings。 |
| 16 | P1 | `16-settings-permissions`、`17-settings-advanced` | 权限/安全页的警示块与高级页的密集开关行使用相近浅底卡片，但风险语义完全不同；警示色只靠小图标，暗色页需复核对比度。 | 给 destructive / warning / informational 三类卡建立语义 token；暗色下用 `getComputedStyle` 量实测对比度，不靠肉眼。 |

| # | 级别 | 证据 | 问题 | 建议 |
| --- | --- | --- | --- | --- |
| 18 | P1 | `03-inspector-changes`、`04-inspector-plan`、`05-inspector-timeline` | 检查器只在有数据时显示 Tab，三张图常常是同一主内容区配不同标题；「改动 / 计划 / 时间线」内容密度差异大但容器尺寸完全一致。 | 按 Tab 语义给内容宽度/行高策略；无数据 Tab 隐藏是对的，但要给一句「当前会话还没有计划」之类的诚实状态，而不是只少一个按钮。 |
| 19 | P1 | `35-dark-home`、`37-dark-plugins`、`38-dark-settings` | 暗色整体可读，但主画布接近纯黑、卡片只靠极细描边分层；插件页开关的珊瑚色和右侧设置页强调块在暗底上饱和度偏高。 | 暗色层级改由 2–3 档表面亮度 + 统一描边承担；强调色降饱和，保留文本/图标对比度；用 `--t-*` 动效 token。 |
| 20 | P2 | `35-dark-home`、`36-dark-session` | 暗色代码块仍是亮色页的纯黑块，与暗画布几乎同色，只剩文字区分；表格浅灰底在暗色里变成局部亮块。 | 代码块使用独立 surface token（不是固定黑），表格/证据块随主题走；禁裸色值。 |
| 21 | P1 | `39-narrow-880-plugins`、`40-narrow-880-chat`、`41-1120-chat` | 880 宽插件页左筛选栏占比过高；880 宽会话页仍能看到右栏边缘，正文列被压得偏窄；1120 宽只是等比例放大，未见真正的断点收束。 | 用容器断点重新定义：<960 收左栏为图标/顶部 chips、隐藏右栏；960–1200 保留两栏但缩正文；≥1200 才恢复完整三栏。 |
| 22 | P2 | `42-session-1440` | 宽屏会话页顶栏「改动 1 / 工具」、会话标题与右上操作区之间的间距偏松；模型菜单打开后与主内容之间没有遮罩层级。 | 顶栏三组信息定宽并统一 gap；浮层统一 elevation token，打开时给背景轻微降层但不动正文布局。 |

## 建议的集中修复顺序

1. **P0 复核 / P1 结构**：GateSlot 三卡统一、880–1200 容器断点、暗色语义表面与强调色降饱和。
2. **目的地页密度**：插件少结果、记忆语义分组、自动化空态、技能/工作树归属裁决。
3. **设置模板分层**：单组 / 表格 / 空态三档；警示语义 token 与按钮层级统一。
4. **P2 打磨**：问候文案、证据块样式、快捷键网格、图表低样本退化、抽屉规范。

修复后复跑 `design-audit.cjs` 生成同机位截图与 `checks.json`，再做前后对比；真机 dev 的最终观感仍需业主验收。
